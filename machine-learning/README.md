# Machine Learning 🌲📈🎯

An interactive, visual course in **classical machine learning** for software engineers: understand, use and **choose** the methods that power most real ML on tables of data, with intuition first. Data and features, linear models, kNN, naive Bayes, SVMs and kernels, decision trees, random forests and gradient boosting (XGBoost, LightGBM, CatBoost), evaluation and tuning, clustering and dimensionality reduction, anomaly detection, time series, recommenders, ranking, classical NLP, interpretability (SHAP), fairness, causal basics, MLOps and ML system design.

Every method answers **🤔 Why this?**: the problem before it, what people tried, why it works (with a tiny numeric example), what it costs and when it fails, and what came next. Every lesson has playgrounds you can break (drag points, grow trees, add boosting rounds, step k-means, slide thresholds), all offline in plain JavaScript, plus current scikit-learn / pandas / XGBoost / LightGBM code, trade-offs, the interview angle and real-world uses with primary sources. It's not a proof course: formulas link to the sibling Math for AI course. Facts and library versions were checked as of November 2026 (scikit-learn 1.9, pandas 3.1, XGBoost 3.4, LightGBM 4.7).

Sibling of `../math-course`, `../ai-engineer`, `../rl-course` and `../system-design-course` (and the upcoming `../deep-learning`): same design system, with cross-links where they help.

## Start

Open `index.html` in a browser (double-click works). Or serve it:

```bash
cd ~/machine-learning && python3 -m http.server 8771
# open http://localhost:8771
```

Progress is saved in your browser's localStorage, separately for `file://` and `localhost`; use **Export / Import progress** on the home page to move it. `review.html` brings old quiz questions back on a spaced-repetition schedule; `glossary.html` explains every term, acronym and tool.

## Labs

One Python lab per phase in `labs/` (`phaseN_*.py`, `# %%` cells with TODOs and ✅ checks; answers in `labs/solutions/`). CPU only, built-in or tiny synthetic datasets, seconds to run.

```bash
cd ~/machine-learning/labs && pip install -r requirements.txt
python3 phase4_trees.py        # stops at the first TODO you haven't filled in
```
