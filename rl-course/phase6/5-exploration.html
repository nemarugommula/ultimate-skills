Phase 6 · Lesson 5

Exploration: curiosity, counts & RND

When rewards are rare, random exploration almost never finds them. Reward the agent for novelty instead.

🧰 You'll need (quick reminders)
  • ε-greedy: explore at random with probability ε (Lesson 1.3).
  • UCB's bonus: try things you're unsure about; the bonus shrinks like 1/√(times tried) (Lesson 1.4).
🎯 Hook

In Labs 4–5, ε-greedy and random sampling were enough, because CartPole pays +1 for every step the pole stays up: reward is everywhere. In the Atari game Montezuma's Revenge, you need a long, precise sequence of jumps and climbs to earn your first point. DQN (2015) scored essentially 0. Random button-mashing never gets there. In 2018, OpenAI's RND (Random Network Distillation), which rewards the agent for visiting unfamiliar screens, became one of the first methods to beat the average human score without human demonstrations. In 2020, DeepMind's Agent57, also driven by novelty bonuses, became the first deep RL agent to beat the human baseline on all 57 Atari games.

💡 Big idea Add an intrinsic reward for novelty: rtotal = renv + β · bonus(s). Rarely visited states pay a bonus, so the agent goes looking for them systematically, instead of hoping randomness gets it there.
🧠 Analogy: the thrill of a new street

Exploring a new city, you get a small thrill from streets you've never walked, and none from your daily route. That thrill pulls you into new neighborhoods systematically, instead of wandering at random. An intrinsic reward for novelty gives the agent the same pull.

🎮 Playground · The long corridor

🎲 ε-greedy Q-learning (ε = 0.1)
🧭 Count bonus + optimism: r + 0.1/√N(s,a) (tried once → +0.1, tried 100 times → +0.01), untried actions start optimistic

ε-greedy almost never reaches the treasure (our test: 3.5% of runs in 200 episodes). It settles for the +0.01 distraction. The count-bonus agent finds it in 100% of runs: it usually first stumbles on it within 2–3 episodes, finishes exploring the rest of the corridor, and after about 40 episodes collects it every time. It gets there because "I've never tried going further right from here" is itself worth checking out.

⚠️ A subtle detail we found while building this demo

A novelty bonus alone, with Q-values starting at 0, didn't work at all (0% success). The agent only receives the bonus after visiting a place, so places it's already been look better than places it hasn't been. The fix is to make untried actions optimistic (Lesson 1.4's "optimism in the face of uncertainty"). It's a good example of why researchers test their intuitions in code.

✏️ Worked example: why random exploration fails in a corridor

A corridor of 10 cells; the only reward is at the far end. A purely random agent picks left or right with 50/50 chance. To reach the end within its first 9 steps, it needs 9 "rights" in a row: (½)9 = 1/512 ≈ 0.2%. (Longer, wandering routes can get there too, but with a step limit they're also unlikely.) Make the corridor 20 cells and it's about 1 in 500,000.

With a novelty bonus, the agent is paid to step onto cells it hasn't visited, so it pushes further along the corridor every episode instead of hoping for a lucky streak.

Novelty at scale: you can't count pixels

🔢

Count-based

bonus = 1/√N(s). Great for tables. For images (where no two frames are exactly equal), use "pseudo-counts": ask a model "how similar is this to everything I've seen?" Familiar → high count, weird → low count.

🔮

Curiosity (ICM, 2017)

Train a model to predict what happens next. Reward = its prediction error: "surprising" means novel. (Watch out for TV screens of random noise: forever surprising, forever distracting.)

🎲

RND (2018)

A fixed, untrained random network turns each state into a weird "fingerprint" of numbers. A second network practises predicting those fingerprints on states the agent visits. It gets good only on states it has practised, so a big prediction error means "I've rarely been here" = novelty. Simple and robust.

🗺️

Go-Explore (2019–21)

Remember promising states, return to one, then explore from there. It cracked Montezuma's Revenge and Pitfall at superhuman level (Nature, 2021).

Math refresher Why 1/√N?

It's the same shape as UCB's bonus (Lesson 1.4): the uncertainty of an estimate from N samples shrinks like 1/√N. The bonus is large for barely-explored places and fades smoothly as they become familiar, never quite reaching zero.

🌍 Where it's used
Count-based novelty for game testing 🧪 Research · 2021 EA SEED: curious agents playtest a 3D level

How: state = position, velocity and 12 sensing rays · action = move, turn, strafe, jump · reward = 0.5 for reaching a new spot, fading to 0 as visits to it approach 500. No game score at all.

Why this method: testers want coverage, not a score. The count bonus pushed 320 agents into every corner, and they found ways out of the map through a planted missing wall.

Novelty bonuses (RND) + a bandit for how much to explore 🧪 Research · 2020 DeepMind: Agent57

How: state = the Atari screen · action = joystick move · reward = game score + a novelty bonus (new this episode × new in its lifetime, via RND). A bandit picks how exploratory each run is.

Why this method: one fixed exploration level is too timid for sparse games and too wasteful for easy ones. It was the first agent above the human benchmark on all 57 Atari games.

🤯 Fun fact

The "noisy TV problem" is real. In a 2018 study on curiosity-driven agents, putting a TV showing random static in a maze made curious agents stop and stare at it, because random pixels are endlessly unpredictable. Novelty is not the same as learnable novelty, which is one reason RND (which predicts a deterministic random function) works better.

🌉 LLM bridge · exploration for reasoning models

When an LLM never stumbles on a correct solution to a hard problem, every sampled answer gets reward 0 and nothing is learned: the Montezuma problem for math. Current approaches include sampling more attempts on hard prompts, keeping entropy from collapsing (Phase 8), giving hints or partial solutions, and rewarding diverse answers. Whether RL can make models discover genuinely new reasoning, rather than just sharpen what they already do, is the pass@k debate in Phase 8.

Check yourself ✅

1. Why does ε-greedy fail in the long corridor?
Undirected (dithering) exploration scales terribly with how far away rewards are, and every greedy step pulls the agent back left toward the +0.01 it already knows about.
2. What is RND's novelty signal?
Familiar states → predictor has learned them → low error. Novel states → high error → bonus.
3. The "noisy TV" problem breaks which approach most?
Pure randomness is unpredictable forever, so prediction-error curiosity stays hooked.
📝 TL;DR
  • Sparse rewards + random exploration = rarely finding anything.
  • Intrinsic rewards for novelty: counts (1/√N), curiosity (prediction error), RND, Go-Explore.
  • Combine a bonus with optimism for untried actions.
  • For LLMs: hard prompts with all-zero rewards are the same exploration problem.
