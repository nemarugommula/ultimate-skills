The 6 words of RL

Learn six words and you can follow almost any RL paper, from game-playing bots to RLHF.

🎯 Hook

The word "reinforcement" comes from animal psychology. In the 1950s B.F. Skinner trained pigeons to play ping-pong by giving them food when they pecked the ball the right way. "Reinforcing" a behavior means rewarding it so it happens more often. Computer scientists borrowed the word, and the ideas came with it.

The six words

We'll use a little robot in a grid as the example. Here are the six words, each with its color:

🤖

1. Agent

The thing that decides and learns. Here: the robot.

🌍

2. Environment

Everything outside the agent that responds to its actions. Here: the grid, walls, gem and lava.

📍

3. State (s)

A snapshot of "where things are right now". Here: the robot's (row, col). That's enough because the walls, gem and lava never move, so position tells you everything that matters for what happens next. (A state with that property is called Markov; more in Phase 2.1.)

🕹️

4. Action (a)

A choice the agent can make. Here: ↑ → ↓ ←.

🍬

5. Reward (r)

A number the environment sends back after each action. Here: 💎 = +10, 🔥 = −10, every step = −1 (so hurry up!).

🧭

6. Policy (π)

The agent's strategy: a rule saying which action to take in each state. This is what RL learns.

Two bonus words:

  • Episode: one complete run from start to finish (until you reach 💎 or 🔥). Like one round of a game.
  • Trajectory: the full record of an episode: state, action, reward, state, action, reward, …

💡 Big idea A policy is just a function from state to action. The whole goal of RL is to find a policy that collects the most reward. The arrows you drew are a policy.
🧠 Analogy: a video game

You (the agent) play a game (the environment). What's on the screen right now is the state. The buttons on your controller are the actions. The points you score are the rewards. One level from start to game-over is an episode. And your way of playing ("when I see a gap, I jump") is your policy. RL is getting better at the game by playing it.

Math refresher Reading RL notation like code

RL papers look scary because of the symbols, but you already know them from programming.

1. Subscripts are array indices

st just means "the state at time step t", the same as states[t]. Time counts the steps: t = 0, 1, 2, …

s0, a0, r1, s1, a1, r2, s2, … "a trajectory": start state, action, reward you got for it, next state, next action, …

Notice that the reward for action a0 is called r1: it arrives at the next tick. (Some papers write r0 instead. Same idea, different counting.)

trajectory = []
s = env.reset()                    # s_0
for t in range(100):
    a = policy(s)                  # a_t
    s_next, r, done = env.step(a)  # r_{t+1}, s_{t+1}
    trajectory.append((s, a, r))
    s = s_next
    if done: break

This loop is a simplified version of the standard interface used across RL, the Gymnasium API. (The real step() returns a couple of extra fields you'll meet in Phase 4.) You'll write this loop yourself in Lab 0.

2. π(a | s): a policy as probabilities

Read the bar | as "given". So π(a | s) means "the probability of choosing action a, given that I'm in state s".

π(↑ | (4,0)) = 0.7 "In cell (4,0), I go up 70% of the time"

A fixed arrow (like the ones you draw in the playground) is also a policy: it just puts 100% on one action.

# deterministic policy: always the same action
def policy(s): return "up"

# random ("stochastic") policy: a probability for each action (they add up to 1)
def policy(s): return {"up": 0.7, "right": 0.2, "down": 0.05, "left": 0.05}

Why use probabilities? Randomness lets the agent explore and try new things. That turns out to be very important (all of Phase 1 is about it). Second reason: a predictable policy can be exploited. In rock-paper-scissors, "always rock" loses to anyone who notices; picking each move 1/3 of the time can't be beaten on average.

🌉 LLM bridge · an LLM is already a policy

An LLM takes in text and outputs a probability for every possible next token. That's exactly π(a | s)! So when people "do RL on an LLM", they're not adding anything strange. They're nudging the probabilities of an existing policy so that it writes responses that earn more reward.

Each response is an episode and each token is an action. Solving a math problem can mean thousands of actions before a single reward ("correct!"). Remember the credit assignment problem from Lesson 1? LLMs have it badly.

🌍 Where it's used
The six words in a ride-hailing app 🏭 In production · 2021 Lyft: matching drivers and riders

How: the matcher thinks one driver at a time · state = the driver's location and the time · action = take this ride request or wait · reward = the fare earned (0 while waiting).

Why this method: the nearest ride isn't always the best one: a trip that ends somewhere busy leads to the next fare. Thinking in states lets Lyft count where each match leaves the driver. Rolled out globally in 2021.

A policy made of probabilities: π(a|s) 🧪 Research · 2019 Meta AI: Pluribus beats poker pros

How: state = your cards plus every bet so far · action = fold, call or raise · reward = chips won or lost when the hand ends · policy = a probability for each action.

Why this method: a fixed rule (“always bluff with a weak hand”) gets spotted and punished. Pluribus, which learned by playing copies of itself, balances its choices so it stays unpredictable, like rock-paper-scissors.

🤯 Fun fact

The symbol π for policy has nothing to do with 3.14159… It's just "p for policy" in Greek. RL researchers ran out of Latin letters a long time ago.

Check yourself ✅

1. In RL, what does the agent actually learn?
The policy is the output of RL. (Some methods also learn a model of the environment or estimate rewards, but those are tools for finding a better policy.)
2. When ChatGPT writes a reply, what is a single "action"?
Each next token is an action, and the state is everything written so far. (Some algorithms treat the whole reply as one big action. You'll see that in Phase 8.)
3. Why give a −1 reward for every step in the gridworld?
Without it, wandering for 1000 steps then reaching 💎 would score the same as going straight there. The reward defines the goal, so choose it carefully. (More on that next lesson.)
📝 TL;DR
  • Agent acts in an environment. At each step: see state, pick action, get reward.
  • A policy π(a|s) = probability of each action in each state. It's what RL learns.
  • Subscript t = array index. st = states[t].
  • An LLM is a policy: state = text so far, action = next token.
