# RL from Zero 🤖🎯🧠

An interactive, visual course on Reinforcement Learning, from "what is a reward?" to how RL trains today's reasoning LLMs and coding agents.

## Start

Open `index.html` in a browser (double-click works). Or serve it:

```bash
cd ~/rl-course && python3 -m http.server 8765
# open http://localhost:8765
```

Your progress (completed lessons and quiz answers) is saved in your browser's localStorage, separately for `file://` and `localhost`. Use **Export / Import progress** on the home page to move it.

Stuck on a term or symbol? `glossary.html` reads every symbol out loud and links each term to the lesson that teaches it. `review.html` brings old quiz questions back on a spaced-repetition schedule.

## Labs

```bash
cd ~/rl-course/labs
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 phase0_env_and_returns.py   # or run cell-by-cell in your editor (# %% cells)
```

Each TODO has ✅ self-checks right after it. Solutions are in `labs/solutions/`.

| Lab | File | Needs | Runtime (laptop CPU) |
|---|---|---|---|
| 0 | `phase0_env_and_returns.py`: gridworld env, returns, policy evaluation | numpy | seconds |
| 1 | `phase1_bandits.py`: ε-greedy, UCB, Thompson | numpy | seconds |
| 2 | `phase2_dynamic_programming.py`: policy/value iteration | numpy | seconds |
| 3 | `phase3_td_learning.py`: MC, TD, SARSA, Q-learning, n-step | numpy | ~10 s |
| 4 | `phase4_dqn.py`: DQN + Double DQN on CartPole | torch, gymnasium | minutes |
| 5 | `phase5_policy_gradients.py`: REINFORCE + PPO on CartPole | torch, gymnasium | minutes |
| 6 | `phase6_advanced.py`: Dyna-Q + SAC on Pendulum | torch, gymnasium | minutes |
| 7 | `phase7_dpo.py`: reward model + DPO on SmolLM2-135M | torch, transformers | 5–30 min (Colab GPU: ~2 min) |
| 8 | `phase8_grpo.py`: GRPO from scratch on SmolLM2-135M | torch, transformers | 15–50 min (Colab GPU: minutes) |
| 9 | `phase9_statistics.py`: bootstrap CIs, IQM, pass@k, power | numpy | seconds |

Labs 7–8 download a ~270 MB model on first run. On Colab: upload the file, `pip install "transformers>=4.45,<5"`, and pick a GPU runtime.

## Structure

```
index.html            home + roadmap (rendered from COURSE in assets/course.js)
glossary.html         searchable glossary, symbols read aloud, math-refresher index
review.html           spaced-repetition review of every lesson quiz
cases.html            five real problems revisited in every recap (case files)
chooser.html          method chooser: problem → method family → lessons
connections.html      the fields RL connects to (control, OR, economics, psychology, neuroscience…)
assets/style.css      design system (callout boxes, color language, playgrounds)
assets/course.js      course manifest, nav/sidebar, progress, quizzes, RL helpers
assets/plot.js        tiny canvas charts (line, bars)
assets/review-bank.js generated by tools/build-review-bank.py (rerun after editing quizzes)
phase0/ … phase9/     lessons (one HTML file each) + recap.html (cheat sheet + lab);
                      phase8/ holds Phase 8A (8.1–8.9, recap.html) and 8B (8.10–8.15, recap-agents.html)
labs/                 Python labs with TODOs; labs/solutions/ has answers
```
