    🔬 How to study this course
    • Play before you read the math. Push the sliders until you can predict what will happen.
    • Do every quiz. If you get one wrong, that's the useful part. Read the explanation, then hit ↻ Try again. A few minutes on the review page every couple of days brings old questions back before you forget them.
    • Do the labs. Coding each algorithm from scratch is what makes it stick.
    • Teach it back. At the end of each phase, explain the big idea out loud in 60 seconds.
    • Stuck on a symbol? The glossary reads every symbol out loud in plain English. Use ← / → to move between lessons.
