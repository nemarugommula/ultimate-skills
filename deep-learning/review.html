💡 How it works

Each question sits in one of six boxes. Get it right and it moves up a box and comes back later: after 1, 3, 7, 16, then 35 days. Miss it and it drops to box 0 and comes back at the end of this session. Questions you missed inside the lessons come first. (This is the Leitner box system for flashcards.) The answer options are shuffled, so you can't answer from memory of the layout.
