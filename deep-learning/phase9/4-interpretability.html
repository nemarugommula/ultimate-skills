Phase 9 · Lesson 4

Interpretability: saliency, probes, circuits, SAEs

A trained network is millions of numbers that work. Interpretability asks which inputs mattered, what the network knows inside, and which mechanism produced an answer. The tools range from a one-line gradient to dictionaries of millions of features pulled out of a frontier LLM.

🧰 You'll need (quick reminders)
  • A gradient with respect to an input says how much the output changes if you nudge that input (math 3.3); backprop computes it (Lesson 1.2).
  • Visualizing CNN filters and activations (Lesson 3.6); hidden layers hold activations, one number per neuron.
  • An autoencoder compresses then rebuilds its input (Lesson 7.1); L1 regularization pushes values to exactly zero (math 7.4).
🎯 Hook

In May 2024, Anthropic found a direction inside Claude 3 Sonnet's activations that lights up for the Golden Gate Bridge: for the words, and for pictures of it. Then they turned that one feature up. For a day, the public could chat with “Golden Gate Claude”, which brought the bridge into nearly every answer. The feature was one of 34 million that a sparse autoencoder pulled out of the model.

A year later, Anthropic traced how Claude 3.5 Haiku answers “the capital of the state containing Dallas”: inside, it represents “Texas” as an intermediate step before saying “Austin”. And when writing a rhyming couplet, it picks the rhyming word (“rabbit”) before it writes the line.

How do you look inside a network and find things like that, and how do you know the picture isn't fooling you? You'll compute saliency maps and watch them fail a classic test, then pack 5 features into 2 neurons and pull them apart again with your own sparse autoencoder.

Why look inside at all?

Accuracy on a test set tells you that a model works, not why. The why matters when:

  • It might be cheating. A classifier can learn a hospital's watermark instead of the disease (a spurious feature). Test accuracy won't show it until it's deployed at a new hospital.
  • Someone needs a reason. A doctor or a loan applicant asks which inputs drove the decision.
  • You want to fix or steer it. Find the feature for “deception” or “bridge”, then monitor it or turn it down.
  • Safety. For very capable models, “it passed our tests” isn't enough; you want to check the mechanism.

💡 Big idea Interpretability methods answer different questions at different depths: attribution (which inputs mattered), probing (what's decodable inside), mechanism (which parts compute it) and features (what concepts exist). Every method can mislead, so each comes with a sanity check: does the explanation change when the model changes?
🧠 Analogy: diagnosing a car

Saliency is pressing each pedal and seeing what the engine does. A probe is plugging a meter into a wire to see if it carries “speed”. Circuit analysis is tracing the wiring diagram from pedal to wheels. A sparse autoencoder is discovering that one bundle of wires actually carries 20 different signals multiplexed together, and building a demultiplexer to separate them.

Saliency maps: ask the gradient

The simplest explanation: take the gradient of the output score with respect to every input. Big gradient = “nudging this input would change the answer a lot”. For an image, plot |∂score/∂pixel| as a heat map: that's a saliency map (Simonyan, Vedaldi and Zisserman, 2013). One backward pass, any model.

Its weakness is in the name: a gradient is local. If the model is already 99.99% sure, the output is flat around the input (the sigmoid is saturated, Lesson 0.4), so every gradient is near zero, even for the inputs that made it sure. Integrated gradients (Sundararajan, Taly and Yan, 2017) fixes that: walk in a straight line from a baseline (a blank input) to the real input, average the gradient along the way, and multiply by how far each input moved. In words: “how much did each input contribute to the change from blank to here?” A nice guarantee, called completeness: the attributions add up exactly to output(input) − output(baseline).

IGi = (xi − baselinei) × average over the path of ∂output/∂xi

🤔 Why this? Saliency maps and integrated gradients
  1. The problem before A CNN says “dog, 97%” and gives no reason. Visualizing filters (Lesson 3.6) shows what units like in general, not why this image got this label.
  2. What people tried Occlusion: grey out patches one by one and watch the score (honest but needs one forward pass per patch); deconvolution-based visualizations.
  3. Why this works The input gradient is the first-order answer to “which pixels would change the score?”, for the price of one backward pass. Integrated gradients sums gradients along a path from a baseline, so saturated inputs still get credit, and the credits add up to the change in output (−0.76 − 0.24 = −1.00 in your playground).
  4. What it costs, when it fails Raw gradients are noisy and vanish in saturated regions (85% of your grid). IG needs a baseline (black image? blurred image? the answer changes with it) and 20–300 backward passes. Worst of all, Adebayo et al.'s 2018 “Sanity Checks for Saliency Maps” found that some popular saliency methods produce nearly the same map after the model's weights are randomized, or after training on random labels: they were mostly showing edges in the image, not the model's reasoning.
  5. What refined it SmoothGrad (average gradients over noisy copies), Grad-CAM for CNNs (Lesson 3.6), the randomization sanity checks themselves as a standard test, and attention-based or circuit-based explanations for transformers (below).

Linear probes: what's written inside?

Saliency looks at inputs. A probe looks at hidden layers. Freeze the network, collect its activations at some layer for many inputs, and train a linear classifier to predict a property (part of speech, sentiment, object depth, whether a sentence is true). If a straight line separates the classes, that information is linearly decodable at that layer. Alain and Bengio (2016) used probes to show that later layers of image networks make the class more and more linearly separable.

✏️ Worked example: probe size and a warning

A layer of a 7B-parameter LLM has 4,096 activations per token. A probe for “is this statement true?” is 4,096 weights + 1 bias = 4,097 parameters, trained on a few thousand labelled sentences in seconds. Compare the model: 7,000,000,000 parameters. The probe is far too small to learn the task itself, so if it scores 90%, the information was already there.

The warning, from this lesson's PyTorch snippet: a probe on the first hidden layer of a small classifier decoded a pure noise input that the task never used with 97% accuracy. “Decodable” does not mean “used”: the network just hadn't bothered to throw it away. To show a model uses a representation, intervene: change it and see if the output changes.

🤔 Why this? Linear probes
  1. The problem before You can't read a 4,096-number activation vector by eye, and individual neurons rarely mean one clean thing.
  2. What people tried Looking at the top-activating examples for each neuron; non-linear (MLP) probes.
  3. Why this works A linear probe is so small that it can't compute much itself: success means the property is laid out along a direction in activation space. It's cheap (seconds), works at every layer, and tells you where in the network information appears. It's also how self-supervised features are scored (Lesson 9.1).
  4. What it costs, when it fails Decodable ≠ used (97% on a noise feature, above). A probe needs labelled data for each property and only finds properties you thought to ask about. A powerful non-linear probe can learn the task itself, so stay linear.
  5. What refined it Causal interventions (activation patching: copy an activation from another input and see what changes), steering vectors (add a direction to change behaviour), and unsupervised feature discovery with sparse autoencoders (below), which doesn't need you to know what to look for.

Circuits: reverse-engineering the mechanism

Mechanistic interpretability tries to explain a behaviour as an algorithm made of the network's own parts. The 2020 “Zoom In” article (Olah and colleagues, Distill) traced curve detectors in an image network back to the earlier edge detectors that build them, weight by weight.

The best-known transformer circuit is the induction head (Olsson et al., 2022). In words: “find the previous time the current token appeared, look at what came right after it, and predict that again”, completing the pattern [A][B] … [A] → [B]. If the text earlier said “Harry Potter” and now says “Harry”, an induction head boosts “Potter”. They are built from two attention heads working together, appear during training in a sudden phase change that coincides with a jump in in-context learning, and are a big part of how LLMs copy from their context (the thing state-space models struggle with, Lesson 9.3).

Superposition: more features than neurons

If every neuron meant one thing, interpretability would be easy: label the neurons. But many neurons are polysemantic: the same neuron fires for cat faces, car fronts and the letter “S”. Anthropic's Toy Models of Superposition (2022) explained why with a tiny experiment you can rerun below: ask a model to store 5 features in only 2 neurons. If features are rarely active at the same time (sparse), the model can cram them in at angles to each other and accept a little interference when two happen to be on together. Neurons then mix several features: polysemantic.

What you should see (seeded): at sparsity 0 the model stores just the 2 most important features, at right angles, and drops the rest. At 0.5–0.8 it stores 4, as two opposite pairs at right angles (smallest angle about 90°, interference ≈ 0: ReLU and a negative bias cancel a feature pointing the opposite way). At 0.9 all 5 fit, as a pentagon (about 72° apart, interference about 0.3, since cos 72° = 0.31), the kinds of geometry the Anthropic paper reports (“digons, triangles, pentagons”). Each neuron now responds to several features: polysemantic. In step 2, a 5-latent SAE with λ = 0.1 is still muddled (4 recovered, 34% interference). A dictionary of 10 with λ = 1 gives 5 of 5, 0% interference; 8 with λ = 0.5 also works (4%). Push λ to 3 and every latent dies. Real SAEs face the same trade: Anthropic's 34-million-latent SAE had about 65% dead latents.

This is a toy: 5 hand-made features in 2 dimensions. Real models are thought to pack far more features into thousands of dimensions; the toy just shows the geometry.

🤔 Why this? Sparse autoencoders (dictionary learning)
  1. The problem before Neurons are polysemantic because of superposition (your pentagon: 5 features in 2 neurons), so labelling neurons fails, and probes only find concepts you already thought of.
  2. What people tried Studying single neurons and their top examples; PCA on activations (finds at most as many directions as dimensions, and they're dense mixtures).
  3. Why this works If the true features are sparse directions, learn an overcomplete set of directions (more latents than neurons) with an L1 penalty so each input is explained by only a few. Each latent then tends to be monosemantic. Anthropic's “Towards Monosemanticity” (2023) trained SAEs on a one-layer transformer's 512-neuron MLP layer, with 512 to 131,072 latents; “Scaling Monosemanticity” (2024) reached 34 million latents on Claude 3 Sonnet, finding abstract, multilingual and multimodal features (the Golden Gate Bridge, code bugs, deception), and showed that turning a feature up changes behaviour.
  4. What it costs, when it fails A big training run on billions of activations; dead latents (65% at 34M); the reconstruction is imperfect, so some of the model's computation is missed; latents can split one concept into many or merge several; labelling millions of latents needs automation. Your playground showed the λ knife-edge: too low is muddled, too high is dead.
  5. What refined it Transcoders and cross-layer transcoders that replace MLP layers with sparse, readable ones, and attribution graphs (2025) that chain features across layers into a circuit for a single prompt (below).

Attribution graphs: following one thought

In March 2025 Anthropic published “circuit tracing”. They replace the model's MLP layers with a cross-layer transcoder (a sparse, interpretable stand-in trained to imitate them), then draw an attribution graph: which features caused which other features, from the prompt to the answer. Applied to Claude 3.5 Haiku, it showed the Dallas → Texas → Austin step, and that the model chooses a rhyming word before writing the line that ends with it.

Its authors are frank about the limits: they estimate the graphs gave “satisfying insight for about a quarter of the prompts” they tried, and their largest replacement model matched the real model's next token on about half of a test set. Interpretability in 2026 is a working microscope with a narrow field of view.

🧰 Tools you'll actually use

Captum (PyTorch's attribution library: Saliency, IntegratedGradients, LayerGradCam), TransformerLens for poking at transformer internals, and open SAE suites and viewers (for example Neuronpedia) for features in open models. The core methods are a few lines of autograd:

import torch, torch.nn as nn

torch.manual_seed(0)
X = torch.randn(2000, 4)
y = (X[:, 0] + 0.5 * X[:, 1] > 0).long()        # features 2 and 3 are pure noise
net = nn.Sequential(nn.Linear(4, 32), nn.ReLU(), nn.Linear(32, 32), nn.ReLU(), nn.Linear(32, 2))
opt = torch.optim.Adam(net.parameters(), lr=1e-2)
for _ in range(300):
    opt.zero_grad(); nn.functional.cross_entropy(net(X), y).backward(); opt.step()

def saliency(model, x, cls):                       # |d score / d input|
    x = x.clone().requires_grad_(True)
    model(x)[:, cls].sum().backward()
    return x.grad.abs().mean(0)

def integrated_gradients(model, x, cls, steps=64):  # (x − baseline) × average gradient on the path
    base = torch.zeros_like(x)
    alphas = torch.linspace(0, 1, steps)[:, None, None]
    path = (base + alphas * (x - base)).requires_grad_(True)       # steps × N × 4
    model(path.reshape(-1, 4))[:, cls].sum().backward()
    return ((x - base) * path.grad.mean(0)).abs().mean(0)

x = X[:200]
print("saliency per feature:", saliency(net, x, 1).numpy().round(2))
print("IG per feature:      ", integrated_gradients(net, x, 1).numpy().round(2))

# sanity check (Adebayo et al.): a fresh, untrained network should give a different map
rand = nn.Sequential(nn.Linear(4, 32), nn.ReLU(), nn.Linear(32, 32), nn.ReLU(), nn.Linear(32, 2))
print("saliency, random net:", saliency(rand, x, 1).numpy().round(2))

# linear probe: is a noise feature linearly readable from the first hidden layer?
with torch.no_grad():
    H = net[1](net[0](X))
probe = nn.Linear(32, 2); popt = torch.optim.Adam(probe.parameters(), lr=1e-2)
target = (X[:, 2] > 0).long()                       # a noise feature the task never needed
for _ in range(300):
    popt.zero_grad(); nn.functional.cross_entropy(probe(H[:1500]), target[:1500]).backward(); popt.step()
acc = (probe(H[1500:]).argmax(1) == target[1500:]).float().mean().item()
print(f"probe accuracy for a noise feature: {acc:.2f}")

# What we got on a laptop CPU (torch 2.8):
# saliency per feature: [31.12 15.64  1.56  0.88]
# IG per feature:       [24.8  17.65  0.94  0.81]
# saliency, random net: [0.04 0.04 0.02 0.03]
# probe accuracy for a noise feature: 0.97

Both attributions correctly rank features 0 and 1 far above the noise features, and the random network's map is completely different (it passes the sanity check). The probe line is the warning from the worked example: decodable is not the same as used.

🎤 Interview angle

“A radiologist asks why your model flagged this X-ray. What can you show, and how much would you trust it?” A strong answer:

  • Attribution: Grad-CAM or integrated gradients over the image, with the baseline stated; check that highlighted regions are anatomy, not text markers or rulers (spurious features).
  • Trust: run the randomization sanity check (maps must change when weights are randomized), and confirm with interventions: occlude the region and see the score drop.
  • Explain superposition and why individual neurons aren't labels; SAEs find more monosemantic features; probes show decodability, not use.
  • Honest limits: explanations are partial; pair them with calibration and out-of-distribution checks (Lesson 9.6).
🏭 In the real world
Millions of features in a production LLM 🏢 Anthropic · 2024 Templeton et al.: Scaling Monosemanticity

How: sparse autoencoders with about 1M, 4M and 34M latents trained on a middle layer of Claude 3 Sonnet.

Why this method: superposition hides concepts from neuron-by-neuron analysis; dictionary learning recovered interpretable, steerable features, including the one behind Golden Gate Claude.

Tracing a model's reasoning step by step 🏢 Anthropic · 2025 Lindsey et al.: On the Biology of a Large Language Model

How: attribution graphs over a cross-layer transcoder replacement of Claude 3.5 Haiku, checked by intervening on the features found.

Why this method: SAEs list concepts but not how they connect; graphs showed multi-step reasoning (Dallas → Texas → Austin) and planning ahead in poems.

The circuit behind in-context copying 🧪 Research · 2022 Olsson et al.: In-context Learning and Induction Heads

How: traced pairs of attention heads that implement [A][B] … [A] → [B], and tracked when they form during training.

Why this method: a mechanism you can point to explains a capability (in-context learning) better than any benchmark score.

The test every saliency method should pass 🧪 Research · 2018 Adebayo et al.: Sanity Checks for Saliency Maps

How: randomize the model's weights layer by layer, or train on random labels, and compare the maps.

Why this method: it exposed that some widely used methods were “independent of both the data the model was trained on, and the model parameters”: pictures of edges, not explanations.

🤯 Fun fact · features that dial up obsession

Golden Gate Claude wasn't a fine-tune or a prompt. Anthropic clamped one SAE feature to a high value inside the network, and the model started steering most conversations toward the bridge. It was available to the public on claude.ai for a short time in May 2024 as a demonstration that the features found by interpretability are causally real: change the feature, change the behaviour.

Input gradients are backprop run to the input (1.2, math 3.5); saturation is the sigmoid story from 0.4; Grad-CAM and filter visualization are 3.6. SAEs are autoencoders (7.1) with L1 (math 7.4). Check yourself

1. Integrated gradients with a black-image baseline gives a cat photo's pixels attributions summing to 0.62. The model says p(cat) = 0.71 for the photo. What must p(cat) be for the black image?
Completeness: the attributions add up to output(input) − output(baseline). 0.71 − p(black) = 0.62, so p(black) = 0.09. If your IG numbers don't satisfy this, you used too few integration steps.
2. Your team's new saliency method produces beautiful, sharp maps. After you randomize all the model's weights, the maps look almost the same. What does that tell you?
Adebayo et al. proposed exactly this test. An explanation of a model must depend on the model. If randomizing the parameters (or training on random labels) leaves the map unchanged, the map is driven by the input alone, however nice it looks.
3. A layer has 512 neurons, and analysis suggests the model represents thousands of distinct concepts there. Most neurons respond to several unrelated things. Which approach is designed for this?
That's superposition: more features than neurons, stored as sparse, non-orthogonal directions, so neurons are polysemantic. PCA finds at most 512 dense directions. An overcomplete, sparse dictionary can pull thousands apart, as in Towards Monosemanticity (512 neurons, up to 131,072 latents).
📝 TL;DR
  • Saliency = input gradient: one backward pass, but local, noisy and blind where the model is saturated. Integrated gradients averages along a path from a baseline; credits add up to the output change.
  • Always run the sanity check: randomize the weights; a real explanation must change.
  • Linear probes show what's linearly decodable at a layer; decodable ≠ used (intervene to show use).
  • Circuits explain mechanisms (curve detectors, induction heads [A][B]…[A]→[B]). Superposition packs more features than neurons, making neurons polysemantic.
  • Sparse autoencoders (overcomplete + L1) recover monosemantic features: 34M in Claude 3 Sonnet, Golden Gate Claude; 2025 attribution graphs chain them into circuits, for about a quarter of prompts.
