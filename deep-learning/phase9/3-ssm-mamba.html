Phase 9 · Lesson 3

State-space models: Mamba and hybrids

Attention remembers every token and pays for it in memory. A state-space model squeezes the past into a fixed-size state, like an RNN, yet trains in parallel like a transformer. Mamba made that state selective, and today's long-context LLMs increasingly mix both.

🧰 You'll need (quick reminders)
  • An RNN keeps a hidden state and updates it one token at a time; LSTM gates decide what to keep and forget (Lessons 5.2, 5.3).
  • Self-attention compares every token with every other: n² work, and at generation time a KV cache (the stored keys and values of all past tokens) that grows with every token (Lessons 6.1, 6.9).
  • A convolution is a weighted sum of nearby inputs with one shared kernel (Lesson 3.2; math 8.3b).
🎯 Hook

In October 2025, IBM released Granite 4.0, a family of open LLMs in which most layers are not attention at all. They are Mamba-2 layers, mixed with ordinary transformer blocks in a 9 : 1 ratio. IBM reports the hybrid needs over 70% less memory for long inputs and many simultaneous users. NVIDIA's Nemotron-H and Nemotron Nano 2 models do something similar: in Nano 2, only 6 of 62 layers are attention.

So the transformer, the architecture behind every chatbot, is being partly replaced by something that looks like a 1980s RNN with a twist.

Why would anyone go back to recurrence, and what does the 10% of attention that's left still do that the rest can't? You'll measure the memory gap yourself, then build a tiny selective memory and make it remember one number through 20 distractors.

Numbers first: the memory bill of attention

When a transformer generates text, it keeps the keys and values of every past token in every layer, so the next token can attend to them. Take a Llama-style 8-billion-parameter configuration: 32 layers, 8 key-value heads of size 128, stored in bf16 (2 bytes):

KV cache per token = 2 (K and V) × 8 heads × 128 × 2 bytes × 32 layers = 131,072 bytes = 128 KiB

Attention's cost grows with every token you've seen; generating each new token also reads that whole cache. An RNN summarizes the past in one fixed-size state: memory stays flat and every step costs the same. The catch: RNNs train one step at a time (slow on GPUs) and forget (Lesson 5.2). State-space models fix the first problem; Mamba attacks the second.

💡 Big idea A state-space model (SSM) is a linear recurrence: statet = A · statet−1 + B · inputt. Because it's linear, the same computation can be run three ways: as a loop (cheap generation), as a convolution or a parallel scan (fast training). Mamba makes A and B depend on the current token, so the model can choose what to write and what to keep: a selective state.
🧠 Analogy: a court reporter versus a note-taker

Attention is a court reporter who keeps a verbatim transcript and rereads all of it before every sentence: perfect recall, and the pile of paper grows all day. An SSM is a note-taker with one index card: after each sentence they update the card. Constant effort, constant space. A plain SSM updates the card the same way for every sentence (“fade old notes by 5%, add the new sentence”). Mamba is a note-taker who decides per sentence: “that's the verdict, write it big; that's small talk, leave the card alone”.

A linear recurrence you can compute three ways

Strip an RNN down to its simplest linear form, one number per channel: ht = a · ht−1 + b · xt. No tanh, no nonlinearity inside the loop. That one change unlocks parallel training.

✏️ Worked example: loop = convolution

a = 0.5, b = 1, inputs x = [1, 2, 3], starting from h0 = 0.

As a loop (RNN view)As a convolution (kernel K = [b, ab, a²b] = [1, 0.5, 0.25])
h10.5·0 + 1 = 11·1 = 1
h20.5·1 + 2 = 2.51·2 + 0.5·1 = 2.5
h30.5·2.5 + 3 = 4.251·3 + 0.5·2 + 0.25·1 = 4.25

Unroll the loop and ht is a weighted sum of past inputs with weights b, ab, a²b, …: exactly a convolution with one long kernel, which a GPU computes for the whole sequence at once (with FFTs, in n log n time). The third way, a parallel scan, combines pairs of steps like a tournament bracket: (a₁, b₁) then (a₂, b₂) equals (a₁a₂, a₂b₁ + b₂), so n steps take about log₂ n rounds. For 1,024 tokens that's 10 rounds instead of 1,024 sequential steps.

A real SSM layer runs this for thousands of channels, with a small state vector per channel instead of one number, and reads the state out with a vector C. S4 (Gu, Goel and Ré, 2021) chose A carefully so the state remembers long histories, and trained it as a long convolution. It was the first model to solve Path-X, a 16,384-step benchmark task where every earlier model scored no better than chance.

🤔 Why this? Linear recurrence / structured state-space models (S4)
  1. The problem before Attention costs n² compute and a KV cache that grows by 128 KiB per token in our 8B example. RNNs have a fixed state, but their nonlinear loop must run one step at a time during training, and gradients vanish over long sequences (Lessons 5.2, 2.1).
  2. What people tried LSTMs and GRUs (gates, still sequential), sparse and sliding-window attention, linear attention (Lesson 6.9), dilated convolutions.
  3. Why this works Keep the recurrence linear and the loop can be rewritten as one long convolution (training: fully parallel) or run step by step (generation: constant memory and time per token). S4's specific choice of the A matrix (from the “HiPPO” theory of compressing a history into a few numbers) lets the state hold information over thousands of steps.
  4. What it costs, when it fails With fixed A and B, the model treats every token the same: it can't decide “this word matters, that one doesn't”. S4 was strong on audio and long-range benchmarks but lagged transformers on language. The fixed-size state is a hard limit on how much it can remember.
  5. What refined it Mamba (2023) made the parameters depend on the input (selective); Mamba-2 (2024) simplified the structure to run on matrix-multiply hardware; hybrids put a few attention layers back.

Mamba: a state that chooses what to remember

In Mamba (Gu and Dao, December 2023), the step size Δ and the matrices B and C are computed from the current token. In words: a large Δ means “reset towards this token and write it in”; a tiny Δ means “ignore this token, keep the state as it is”. That's an input-dependent gate, much like an LSTM's, but on a linear recurrence. The price: with parameters that change at every step there's no single kernel, so the convolution trick is gone. Mamba replaces it with a hardware-aware parallel scan that keeps the big state in fast on-chip memory.

What you should see: with a fixed gate of 0.3 the key is overwritten within a few tokens: its share is 0.02% and the answer is just a blend of recent filler. Lower the gate and the share creeps up, but it can never pass 1 ÷ 21 ≈ 4.8%: a fixed gate either forgets the key fast or averages it equally with all 20 distractors. Switch to selective, set the key gate to 1 and the filler gate to 0: the answer is the key, 100%. Even a filler gate of 0.005 lets about 10% leak away over 20 tokens (0.995²⁰ = 0.905), which is why real Mamba layers can push Δ to nearly zero for irrelevant tokens. With two keys, a key gate of 1 overwrites the old key with the new one: “remember the latest instruction”.

🤔 Why this? Selective state spaces (Mamba)
  1. The problem before S4-style SSMs apply the same update to every token. You just saw the ceiling: a fixed gate can't keep one important token through 20 distractors (≤ 4.8% of the state). Language is full of filler between the words that matter.
  2. What people tried Gated linear RNNs, linear attention, adding short convolutions and gates around S4 (H3, Hyena).
  3. Why this works Make Δ, B and C functions of the token. Now each token decides whether to write itself in (big Δ) or leave the state alone (tiny Δ): your selective playground went from 0.02% to 100%. The authors designed it around synthetic tasks like selective copying and induction heads (“after A came B before, so predict B”). Mamba reported 5× higher generation throughput than transformers of similar size, and a 3B Mamba matching transformers twice its size.
  4. What it costs, when it fails No convolution shortcut, so it needs a custom scan kernel (fast on GPUs, harder to port). And the state is still a fixed size: whatever wasn't written in is gone. Tasks that need exact recall of something arbitrary from far back (copy this 500-character string, find the phone number in this document) are where it loses to attention.
  5. What refined it Mamba-2 (2024): simpler A (a scalar per head), much bigger states, 2–8× faster; and hybrids with a few attention layers for exact recall.

Mamba-2: an SSM is a kind of attention

Dao and Gu's 2024 paper (“Transformers are SSMs”) showed that if A is restricted to a scalar times the identity, a selective SSM equals a form of masked linear attention: the whole sequence's output is one big matrix (lower-triangular, with decaying weights) times the inputs. They call it structured state space duality (SSD). Practical payoff: the computation can be done with matrix multiplications, which GPUs are built for. Their SSD layer is 2–8× faster than Mamba's scan and allows states 8× larger or more.

It also says something conceptual: attention and SSMs are two ends of one family. Attention keeps every token's key and value (memory grows); an SSM compresses them into a running sum with decay (memory fixed).

Where SSMs fall short: copying and recall

Jelassi et al. (2024), in a paper titled “Repeat After Me: Transformers are Better than State Space Models at Copying”, proved that a two-layer transformer can copy strings of exponential length, while SSMs are “fundamentally limited by their fixed-size latent state”. Testing pretrained models, they found transformers “dramatically outperform” SSMs at copying and retrieving information from context. The Zoology study (Arora et al., 2023) found that 82% of the quality gap between attention and attention-free models on real text came from associative recall (“earlier, key K was paired with value V; what goes with K?”): a 70M-parameter attention model beat a 1.4B-parameter attention-free one at it.

That's the court reporter versus the index card again: if you didn't know a detail would matter, it isn't on the card.

🤔 Why this? Hybrid models: mostly SSM, a little attention
  1. The problem before Pure transformers: KV cache grows with context (16 GiB at 128K in our example, per user). Pure SSMs: constant memory, but weaker at exact copying and recall.
  2. What people tried Sliding-window attention (forgets beyond the window), compressing the KV cache (Lesson 6.9), pure SSM LLMs.
  3. Why this works Most layers do “local” work, blending nearby context, which a cheap SSM layer does well. A few attention layers keep an exact lookup into the full history for recall. Memory then scales with the number of attention layers: your playground fit a 1M context in 24 GiB with 5 of 32 attention layers, where all-attention needs 128 GiB.
  4. What it costs, when it fails Two kinds of layer to implement, optimize and serve; a ratio to tune; the attention layers' cache still grows, just more slowly. IBM shipped a transformer-only Granite 4.0 Micro for platforms without hybrid support.
  5. What refined it Jamba (AI21, March 2024): 1 attention layer per 7 Mamba layers plus mixture-of-experts (Lesson 6.10), 52B total / 12B active parameters, 256K context on one 80 GB GPU. NVIDIA Nemotron-H (2025): most attention layers replaced by Mamba-2, up to 3× faster inference than similar transformers; Nemotron Nano 2: 6 attention layers out of 62, up to 6× throughput on long reasoning outputs. IBM Granite 4.0 (October 2025): Mamba-2 and transformer blocks 9 : 1.

🧰 Tools you'll actually use

The official mamba_ssm package (GitHub state-spaces/mamba) provides Mamba and Mamba2 layers with fused CUDA kernels; Hugging Face transformers includes Mamba, Mamba-2, Jamba, Granite 4.0 hybrid and others, so loading one looks like loading any causal LM. The core math runs in plain PyTorch on a CPU:

import torch, torch.nn.functional as F

torch.manual_seed(0)
T, a, b = 1000, 0.95, 0.5
x = torch.randn(T)

# 1) RNN-style: one step at a time, a fixed-size state
h, hs = torch.tensor(0.0), []
for t in range(T):
    h = a * h + b * x[t]
    hs.append(h)
h_loop = torch.stack(hs)

# 2) S4-style: the same thing as ONE convolution with kernel K = [b, ab, a²b, ...]
K = b * a ** torch.arange(T, dtype=torch.float32)
h_conv = F.conv1d(F.pad(x, (T - 1, 0))[None, None], K.flip(0)[None, None])[0, 0]
print("loop vs convolution, max difference:", f"{(h_loop - h_conv).abs().max().item():.1e}")

# 3) Mamba-style: the gate depends on the input, so there is no single kernel any more
x_sel = torch.zeros(21); x_sel[0] = 7.0; x_sel[1:] = torch.randint(0, 10, (20,)).float()
is_key = torch.zeros(21, dtype=torch.bool); is_key[0] = True
g = torch.where(is_key, 1.0, 0.0)        # write the key, ignore the filler
h = torch.tensor(0.0)
for t in range(21):
    h = (1 - g[t]) * h + g[t] * x_sel[t]  # selective update
print("state after 20 distractors:", h.item())

g_fixed = torch.full((21,), 0.3)          # one gate for every token (no selection)
h = torch.tensor(0.0)
for t in range(21):
    h = (1 - g_fixed[t]) * h + g_fixed[t] * x_sel[t]
print("same, with a fixed gate of 0.3:", round(h.item(), 2))

# What we got on a laptop CPU (torch 2.8):
# loop vs convolution, max difference: 9.5e-07
# state after 20 distractors: 7.0
# same, with a fixed gate of 0.3: 4.97

Gotcha: F.conv1d is cross-correlation, so the kernel is flipped and the input left-padded to keep it causal (no peeking at future tokens). For long sequences real SSM code uses FFT convolutions or a scan kernel, not a Python loop.

🎤 Interview angle

“What is Mamba, and why are new LLMs hybrids?” A strong answer:

  • Attention's KV cache grows linearly with context (do the arithmetic: layers × 2 × KV heads × head dim × bytes per token) and prefill is n²; an SSM keeps a fixed-size state.
  • A linear recurrence can be computed as a loop (generation), a convolution (S4) or a parallel scan (training), unlike a nonlinear RNN.
  • Mamba's selectivity: Δ, B, C depend on the token, so it chooses what to write and what to ignore; costs the convolution trick, needs a scan kernel.
  • Weakness: fixed state limits exact copying and recall (Jelassi et al. 2024; Zoology). Hybrids keep a few attention layers (Jamba 1 : 7; Granite 4.0 9 : 1; Nemotron-H) for recall and get most of the memory savings.
🏭 In the real world
The selective SSM 🧪 Research · 2023 Gu & Dao: Mamba: Linear-Time Sequence Modeling with Selective State Spaces

How: input-dependent Δ, B, C; a hardware-aware parallel scan; a simple block with no attention and no separate MLP.

Why this method: linear scaling in sequence length and 5× generation throughput versus similar-size transformers, while matching their quality on language.

The first production-grade hybrid 🏢 AI21 Labs · 2024 Lieber et al.: Jamba: A Hybrid Transformer-Mamba Language Model

How: blocks of 8 layers with 1 attention and 7 Mamba layers, mixture-of-experts every other layer; 12B active of 52B total parameters.

Why this method: a 256K-token context that fits on a single 80 GB GPU, with throughput far above a similar-size transformer.

Hybrids for long reasoning traces 🏢 NVIDIA · 2025 NVIDIA: Nemotron Nano 2, a hybrid Mamba-Transformer reasoning model

How: 62 layers: 28 Mamba-2, 28 feed-forward and only 6 self-attention layers spread through the model (the Nemotron-H recipe).

Why this method: reasoning models generate very long outputs, where per-token cost matters most; NVIDIA reports up to 6× higher throughput than Qwen3-8B at similar accuracy.

Enterprise LLMs on less memory 🏢 IBM · 2025 IBM: Granite 4.0 hybrid models

How: Mamba-2 layers and transformer blocks in a 9 : 1 ratio, open weights under Apache 2.0.

Why this method: long documents and many concurrent sessions are memory-bound; IBM reports over 70% less RAM than conventional transformers for those workloads.

🤯 Fun fact · the benchmark nobody could pass

Path-X shows a model a 128 × 128 image as a flat sequence of 16,384 pixels and asks whether two dots are connected by a dashed path. When the Long Range Arena benchmark was published in 2020, every model tested, ten transformer variants included, was marked FAIL on it: none learned anything. S4 was the first to solve it, which is what made the deep-learning world take state-space models seriously.

Check yourself

1. A model has 40 layers, 8 KV heads of size 128, and stores K and V in bf16 (2 bytes). How big is the KV cache for one 64K-token (65,536) sequence?
Per token: 2 (K and V) × 8 × 128 × 2 bytes × 40 layers = 163,840 bytes = 160 KiB. Times 65,536 tokens = 10,737,418,240 bytes = 10 GiB. An SSM layer's state would stay the same size at any length.
2. A pure-Mamba model summarizes long documents well but fails when asked to quote a 12-digit account number from page 3 of a 50-page contract. A transformer of the same size gets it right. Best explanation and fix?
An SSM compresses the past into a fixed state as it reads; if the model didn't write the number in, it's gone. Attention keeps every token's key and value, so it can look the number up. That's the copying/recall gap measured by Jelassi et al. and the Zoology study, and why hybrids keep some attention layers.
3. Why can S4 be trained as one big convolution, while Mamba can't?
A convolution applies the same kernel everywhere. That's only true when the recurrence's parameters are fixed (time-invariant). Mamba's selectivity makes them input-dependent, which is exactly what lets it choose what to remember, and what forces a different parallel algorithm. Both are still linear in the state.
📝 TL;DR
  • Attention's KV cache grows per token (128 KiB per token in a Llama-style 8B: 16 GiB at 128K); an SSM keeps a fixed-size state.
  • A linear recurrence h = a·h + b·x can run as a loop (generation), a convolution (S4) or a parallel scan (training).
  • Mamba is selective: Δ, B, C depend on the token, so it writes what matters and ignores filler. A fixed gate can't keep 1 token through 20 (≤ 4.8%); a selective one can (100%).
  • Mamba-2 (SSD) shows SSMs are a form of masked linear attention and runs on matmuls. Weakness: exact copying and recall.
  • 2024–26 LLMs mix them: Jamba 1 : 7, Nemotron-H / Nano 2 (6 of 62 layers attention), Granite 4.0 9 : 1.
