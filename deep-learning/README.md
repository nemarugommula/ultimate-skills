# Deep Learning 🧠⚡🎨

An interactive, visual course that gives a beginner a **deep, intuitive understanding of how neural networks work and why every technique exists**: neurons and activations, training and optimizers, making deep nets train, CNNs, detection and segmentation, sequences, transformers, generative models, audio and multimodal models, robustness, and training at scale.

Every technique gets a **🤔 Why this?** box: the problem before it, what people tried, why it works (with numbers), what it costs and when it fails, and what refined it. Tiny networks train live in your browser so you can break them on purpose: swap activations and watch gradients vanish, kill ReLUs, race optimizers, paint convolution kernels, drag boxes for IoU, edit attention maps, scrub a diffusion process. Each phase ends with a recap, a game, a build-it-yourself problem and a CPU-only PyTorch lab. Facts, papers and library APIs were checked against their sources as of late 2026.

It isn't a proof course: formulas link to the sibling **Math for AI** course (`../math-course`). RLHF and RL fine-tuning live in `../rl-course`; applied LLM work (RAG, evals, agents, fine-tuning, serving) lives in `../ai-engineer`; classical ML in `../machine-learning`; self-driving and robotics in `../autonomous-systems`. Same design system, with cross-links where they help.

## Start

Open `index.html` in a browser (double-click works). Or serve it:

```bash
cd ~/deep-learning && python3 -m http.server 8772
# open http://localhost:8772
```

Progress is saved in your browser's localStorage, separately for `file://` and `localhost`; use **Export / Import progress** on the home page to move it. `review.html` brings old quiz questions back on a spaced-repetition schedule; `glossary.html` explains every term, acronym and architecture.

## Labs

Each phase has a small PyTorch lab in `labs/` (`# %%` cells, TODOs with ✅ checks) and its solution in `labs/solutions/`. CPU only, synthetic data, no downloads, each runs in under a minute.

```bash
pip install -r labs/requirements.txt
cd labs && python3 phase0_neurons.py           # fill the TODOs until every check passes
MPLBACKEND=Agg python3 solutions/phase0_neurons.py
```

## Structure

```
index.html            home + roadmap (rendered from COURSE in assets/course.js)
review.html           spaced-repetition review of every lesson quiz
glossary.html         searchable glossary (generated from tools/glossary/*.json)
assets/style.css      design system (callout boxes, the 🤔 Why this? box, color language, playgrounds)
assets/course.js      course manifest, nav/sidebar, progress, quizzes, MX helpers
assets/nn.js          deep-learning toy kit for playgrounds (trainable MLP, activations, optimizers, conv, IoU/NMS, attention, STFT, drawing)
assets/plot.js        tiny canvas charts · assets/plane.js 2D plane with draggable points · assets/flow.js animated diagrams
assets/review-bank.js generated by tools/build-review-bank.py (rerun after editing quizzes)
phase0/ … phase10/    lessons + recap.html per phase (phase10/recap.html is the graduation page)
labs/                 one PyTorch lab per phase + solutions/
tools/                headless page test harness, review-bank and glossary builders, nnload.js (nn.js in node)
```
