# Phase 6 cheat-sheet lines (lessons 6.1–6.6), for the recap writer

- **6.1 Self-attention** — `softmax(QKᵀ/√d_k)·V`. Every token scores every token; divide by √d because q·k has variance d (unscaled at d = 64: 35% of rows one-hot in the lesson's demo). Causal mask = −∞ above the diagonal; cost n² per head per layer. Tools: `F.scaled_dot_product_attention(q, k, v, is_causal=True)`.
- **6.2 Multi-head attention** — h heads of width d/h, concat, × W_O: same 4d² weights and ≈ n²·d score work as one head, but h·n² attention-map memory. Heads specialize (BERT det→noun 94.3%) and many are prunable (38 of 48 heads, −0.15 BLEU). Tools: `nn.MultiheadAttention`, reshape to (B, h, n, d/h) + SDPA.
- **6.3 Positional encodings** — attention is permutation-blind. Learned table (BERT 512, GPT-2 1,024) → sinusoids → relative (Shaw +1.3 BLEU) → RoPE: rotate q, k by position·θ so q·k depends only on n − m (Llama 3 base 500k; Qwen3 1M); ALiBi = distance penalty (BLOOM). Tools: a 10-line `rope()`; `rope_theta` in HF configs.
- **6.4 Transformer block** — `x += Attn(Norm(x)); x += MLP(Norm(x))`: attention mixes tokens (4d²), MLP thinks per token (8d², 4× width, GELU/SwiGLU). Pre-norm (GPT-2 →) keeps a clean residual path and trains without warm-up (Xiong 2020); post-norm piles gradients near the output. GPT-2 small = 124,439,808 params. Tools: `nn.TransformerEncoderLayer(norm_first=True)`, `nn.RMSNorm`, nanoGPT.
- **6.5 Encoder / decoder / encoder–decoder** — the mask is the architecture: BERT full (understand, embed, classify), GPT causal (generate), T5/Whisper full + causal + cross-attention (Q from decoder, K/V from encoder). Decoder-only won general LLMs: one objective, prompting for any task, best zero-shot after unsupervised pretraining (Wang et al. 2022). Tools: `AutoModel` / `AutoModelForCausalLM` / `AutoModelForSeq2SeqLM`, sentence-transformers.
- **6.6 Tokenization** — BPE: repeatedly merge the most frequent pair; byte-level base of 256 means nothing is unknown. Vocab size trades sequence length vs V×d table: GPT-2 50,257; BERT 30K WordPiece; T5 32K SentencePiece; Llama 3 128K (3.17 → 3.94 chars/token); Qwen3 151,669; Gemma 3 262k. Languages can differ up to 15× in tokens. Tools: HF `tokenizers`, `tiktoken` (o200k_base), `AutoTokenizer`.
