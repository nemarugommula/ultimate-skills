🔬 How to study this course
  • Predict before you press. Every playground starts with a 🔮 prediction. Commit to a guess; the surprise is the lesson.
  • Break it on purpose. Each playground has a way to make training fail (vanishing gradients, dead units, divergence, mode collapse). Find it, then fix it.
  • Ask “why this?” For every technique, say out loud what broke before it and what it costs. That's the deep understanding interviewers test.
  • Run the labs. Each phase has a small PyTorch lab (labs/) that runs on a laptop CPU in seconds.
  • Review. Ten questions a day in 🔁 Review keep old phases fresh. Use ← / → to move between lessons.
