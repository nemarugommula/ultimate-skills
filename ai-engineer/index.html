🔬 How to study this course
  • Break the playgrounds. Every one has a way to make retrieval miss, the judge lie or the agent loop. Find it, then find the fix.
  • Run the code. The 🧰 boxes have real snippets; try them with any provider's API key or a local model via Ollama.
  • Build the projects. Each recap ends with a build-it-yourself problem. Sketch the pipeline and its eval before opening the reveal.
  • Measure everything. Phase 5 (evals) is what separates a demo from a product. Come back to it often.
  • Teach it back. At the end of each phase, explain the big idea out loud in 60 seconds, like you would in an interview. Use ← / → to move between lessons.
