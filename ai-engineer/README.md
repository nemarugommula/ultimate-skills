# AI Engineer 🤖📚🧪

An interactive, visual course that takes a software engineer to **senior AI engineer** level: building LLM products, every major kind of RAG, vector search, evals, agents and MCP, fine-tuning and serving, LLMOps, safety, red teaming and AI system design. Based on the roadmap.sh AI Engineer and AI Agents roadmaps, expanded to senior depth, with a Python refresher for AI work.

Every lesson has playgrounds you can break (all offline, no API keys), real code for the tools teams use, trade-offs, startup-vs-big-tech advice, and what senior interviewers listen for. Facts, model names and APIs were checked against official docs as of late 2026.

Sibling of `../rl-course`, `../math-course` and `../system-design-course`: same design system, with cross-links where they help.

## Start

Open `index.html` in a browser (double-click works). Or serve it:

```bash
cd ~/ai-engineer && python3 -m http.server 8766
# open http://localhost:8766
```

Progress is saved in your browser's localStorage, separately for `file://` and `localhost`; use **Export / Import progress** on the home page to move it. `review.html` brings old quiz questions back on a spaced-repetition schedule; `glossary.html` explains every term, acronym and tool.

## Phases

| Phase | Topic |
|---|---|
| 0 | Foundations: the role, how LLMs work, tokens & cost, the model landscape, APIs, when not to use an LLM |
| P | Python for AI engineers: Pythonic idioms & typing, generators, async/await, concurrency & the GIL, memory & GC, production Python (FastAPI, Pydantic, uv, pytest), NumPy & pandas |
| 1 | Prompt & context engineering: prompting, reasoning, structured output & function calling, context engineering & caching, prompts as code |
| 2 | Embeddings & vector search: embeddings, ANN indexes (HNSW, IVF, PQ), vector databases, hybrid search, other embedding uses |
| 3 | RAG fundamentals: why RAG, ingestion, chunking strategies, retrieval & reranking, grounded generation, an end-to-end pipeline |
| 4 | Advanced RAG: query transformation, advanced indexing, GraphRAG, agentic/self-correcting RAG, multimodal RAG, text-to-SQL, RAG in production, RAG pipelines at scale |
| 5 | Evaluation: eval-driven development, metrics, LLM-as-judge, RAG & agent evals, eval ops, datasets, human eval, evals by task, safety evals, rigorous comparison |
| 6 | Agents & tools: the agent loop, tools & MCP, workflow patterns, memory, frameworks, reliability, architectures, building from scratch, MCP servers, agents in practice |
| 7 | Customizing & serving models: fine-tuning (LoRA/QLoRA), preference tuning & distillation, open models & local inference, serving at scale, domain adaptation |
| 8 | Production, safety & multimodal: LLMOps, cost & latency, guardrails, multimodal AI, responsible AI |
| R | AI red teaming & security: threat modelling, prompt injection & jailbreaks, attacking agents & tools, data & model attacks, running an engagement |
| 9 | Becoming senior: AI system design, AI product & UX, interview & portfolio, vertical AI, forward deployed engineering |

## Structure

```

review.html           spaced-repetition review of every lesson quiz
glossary.html         searchable glossary of terms, acronyms, models and tools
assets/style.css      design system (callout boxes, color language, playgrounds)
assets/course.js      course manifest, nav/sidebar, progress, quizzes, MX helpers
assets/ai.js          offline NLP toy kit for playgrounds (tokens, BM25, toy embeddings, chunkers, RRF, MMR)
assets/flow.js        animated pipeline/architecture diagrams
assets/plot.js        tiny canvas charts (line, bars)
assets/review-bank.js generated by tools/build-review-bank.py (rerun after editing quizzes)
phase0/ phasep/ phase1/ … phase8/ phaser/ phase9/   lessons + recap.html per phase
tools/                headless page test harness, review-bank builder
```
