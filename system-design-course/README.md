# System Design at Scale 🏗️⚡🐳

An interactive, visual course that takes you from “I can build features” to designing, deploying and scaling systems for millions of users: as a senior/lead engineer at big tech or a founding engineer at a startup. Every lesson has simulators you can break, the real tools companies run (Redis, Kafka, Postgres, Docker, Kubernetes, Terraform, Prometheus, Grafana, OpenTelemetry), the trade-offs, startup-vs-big-tech advice, and what senior interviewers listen for.

Sibling of `../rl-course` and `../math-course`: same design system.

## Start

Open `index.html` in a browser (double-click works). Or serve it:

```bash
cd ~/system-design-course && python3 -m http.server 8766
# open http://localhost:8766
```

Progress (completed lessons and quiz answers) is saved in your browser's localStorage, separately for `file://` and `localhost`. Use **Export / Import progress** on the home page to move it. `review.html` brings old quiz questions back on a spaced-repetition schedule; `glossary.html` explains every term and tool.

## Structure

```
index.html            home + roadmap (rendered from COURSE in assets/course.js)
review.html           spaced-repetition review of every lesson quiz
glossary.html         searchable glossary of terms, acronyms and tools
assets/style.css      design system (callout boxes, color language, playgrounds)
assets/course.js      course manifest, nav/sidebar, progress, quizzes, MX helpers
assets/flow.js        animated architecture diagrams (nodes, edges, moving request packets)
assets/plot.js        tiny canvas charts (line, bars)
assets/review-bank.js generated by tools/build-review-bank.py (rerun after editing quizzes)
phase0/ … phase8/     lessons (one HTML file each) + recap.html (cheat sheet + design problem)
tools/                headless page test harness, review-bank builder
```

| Phase | Topic |
|---|---|
| 0 | Foundations: how seniors think, DNS/TCP/TLS/HTTP, estimation, APIs, availability & SLOs |
| 1 | Scaling the request path: horizontal scaling, load balancers, caching, CDNs, rate limiting, gateways |
| 2 | Data at scale: SQL vs NoSQL, indexes, replication, sharding & consistent hashing, transactions, CAP, specialised stores |
| 3 | Async & distributed: queues, Kafka, event sourcing & CQRS, idempotency & retries, consensus, clocks/vector clocks & gossip, sagas & outbox, batch/stream pipelines |
| 4 | Microservices: when to split, boundaries & DDD, communication & service mesh, resilience, API evolution, auth, CORS/CSRF & cookies |
| 5 | Containers & cloud: Docker, Kubernetes core and production, Terraform/Helm/GitOps, cloud building blocks |
| 6 | Shipping & running: CI/CD, SemVer & releases, safe deployments, observability, incidents, capacity & cost, security |
| 7 | Designing real systems: framework, URL shortener, news feed, chat, video, ride sharing, payments, notifications |
| 8 | Becoming senior: design docs, trade-offs, founding-engineer playbook, SRE culture, the senior interview |
