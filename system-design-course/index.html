🔬 How to study this course
  • Break the simulators. Every playground has a way to cause an outage. Find it, then find the fix.
  • Do the numbers by hand. Back-of-the-envelope estimation is the skill interviewers test first.
  • Try the tools. The 🧰 boxes have commands you can run locally with Docker.
  • Design it yourself. Each recap ends with a design problem. Sketch your answer before you open the reveal.
  • Teach it back. At the end of each phase, explain the big idea out loud in 60 seconds, like you would in an interview. Use ← / → to move between lessons.
