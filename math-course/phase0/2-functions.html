Functions: machines that turn inputs into outputs

A function is a rule: number in, number out. Every AI model is one, and a deep network is just simple functions stacked on top of each other.

🧰 You'll need (quick reminders)
  • A model is a function with adjustable knobs, and training turns the knobs to reduce the error (Lesson 0.1).
  • Negative numbers: 2 × (−3) = −6 and (−2) × (−3) = +6.
  • A point (3, 5) on a graph means “go 3 across, then 5 up”.
🎯 Hook

In 2012 a neural network called AlexNet crushed the ImageNet image-recognition contest and kicked off the deep-learning boom. One of its key tricks was swapping one tiny function for another: instead of a smooth S-shaped curve, each neuron used “if the number is negative, output 0; otherwise pass it through”.

In the paper's test, a network with this function reached its target training error six times faster than the same network with the old S-curve. That function is called ReLU, and by the end of this lesson you'll build any shape you like out of it.

Numbers first: a temperature converter

To turn Celsius into Fahrenheit you multiply by 1.8 and add 32:

0 °C → 0 × 1.8 + 32 = 32 °F  ·  10 °C → 18 + 32 = 50 °F  ·  100 °C → 180 + 32 = 212 °F

That's a function: a rule that takes one number in and gives exactly one number out. Give it the same input twice and you always get the same output. Mathematicians give the rule a name, like f, and write:

f(x) = 1.8 x + 32 Read “f of x equals 1.8 times x plus 32”. The brackets do not mean multiply: f(x) means “the output of machine f when you feed it x”. So f(10) = 50.

If you plot every pair (input, output) as a point, you get the function's graph. For this one, the points (0, 32), (10, 50), (100, 212) all lie on one straight line.

The straight line: y = wx + b

The converter is the most important function shape in AI: multiply by something, add something. In AI we name the two numbers w (for weight) and b (for bias):

y = w x + b “y equals w times x plus b.” w is the slope: how much y goes up when x goes up by 1. b is the intercept: the value of y when x is 0, where the line crosses the vertical axis.
x: the inputw, b: the knobs (parameters)y: the output
🧠 Analogy: a taxi meter

A taxi charges $3 to get in and $2 per km. A 5 km ride costs 2 × 5 + 3 = $13. The $2 per km is the slope w (every extra km adds $2), the $3 is the intercept b (what you pay for a 0 km ride). The distance is the input x, the fare is the output y.

Notice what the knobs do. w tilts the line (negative w = downhill), b slides it up and down. For the bent machines, w and b also decide where the bend happens: ReLU(wx + b) switches on where wx + b = 0.

Functions that bend

Straight lines can't describe everything. Three bendy machines show up again and again:

  • Powers: x² (“x squared”, x × x) makes a U shape: 2² = 4, (−2)² = 4. Lesson 0.3 is all about powers.
  • Step: output 1 if the input is positive, else 0. A yes/no switch, used by the very first neural networks.
  • ReLU (“rectified linear unit”): keep positive numbers, turn negatives into 0.
ReLU(x) = max(0, x) “ReLU of x is the larger of 0 and x.” ReLU(3) = 3, ReLU(0.5) = 0.5, ReLU(−2) = 0. It's a hockey stick: flat, then a straight ramp.

Composition: machines in a row

Now connect two machines: the output of one becomes the input of the next. Let g(x) = 2x + 1 and f(u) = ReLU(u). Feed in x = −3:

g(−3) = 2 × (−3) + 1 = −5  →  f(−5) = ReLU(−5) = 0
f(g(x)) “f of g of x”: do the inside machine g first, then feed its answer into f. Read it from the inside out.

Order matters. Do f first: f(−3) = 0, then g(0) = 2 × 0 + 1 = 1. Different answer.

Here's the surprise that makes neural networks work. Stack two straight lines: g(x) = 3x + 1, then h(u) = 2u + 5. You get h(g(x)) = 2(3x + 1) + 5 = 6x + 7. Still a straight line. A hundred straight-line layers stacked up are no better than one. Put a bend like ReLU between them, and suddenly the stack can make curves, kinks and bumps.

💡 Big idea A neural network is a big function made of small functions: straight-line steps (wx + b) with a simple bend (like ReLU) after each one, stacked as layer3(layer2(layer1(x))). The bends are what let it fit shapes a line never could.
✏️ Worked example: one neuron, four inputs

A “neuron” computes y = ReLU(2x − 1). Run it on x = −1, 0, 1, 2:

  • Inside first: 2x − 1 = −3, −1, 1, 3.
  • Then ReLU: 0, 0, 1, 3.

So the neuron is “off” (outputs 0) for small inputs and “on” for big ones. It switches on exactly where 2x − 1 = 0, at x = 0.5. Check it in the machine above: ReLU, w = 2, b = −1.

Build any shape from hockey sticks

One ReLU is boring: flat, then a ramp. But add several of them, each switching on at a different place and each with its own strength, and you can draw almost anything.

Math refresher slope = rise over run

Pick two points on a line, say (1, 5) and (3, 9). Going from the first to the second you move 2 across (the run) and 4 up (the rise). Slope = rise / run = 4 / 2 = 2: every step of 1 to the right goes up 2.

A slope of 0 is flat, a negative slope goes downhill. Phase 3 (calculus) is about measuring the slope of curves, not just lines, which is exactly how a model figures out which way to turn its knobs.

🐍 In code 
import numpy as np
def f(x): return 1.8 * x + 32          # a function is a machine: f(10) == 50.0
relu = lambda x: np.maximum(0, x)         # works on whole arrays at once
relu(np.array([-2, 0.5, 3]))                 # array([0. , 0.5, 3. ])

import torch.nn as nn                       # a real network = functions in a row
net = nn.Sequential(nn.Linear(1, 5),          # 5 lines: w·x + b, each with its own knobs
                    nn.ReLU(),                # bend each one
                    nn.Linear(5, 1))          # add them up with strengths, like the builder
🌍 Where it's used
w·x + b with a yes/no step 📜 History · 1958 Rosenblatt's perceptron

How: multiply each input by a weight, add a bias, then apply the step function: output 1 (“yes”) if the total is positive, else 0. One straight-line function followed by one bend.

Why this method: it's the simplest machine that can learn a yes/no decision from examples: the knobs are adjusted whenever it gets one wrong.

ReLU as the bend between layers 🖼️ Deep learning · 2012 AlexNet (Krizhevsky, Sutskever & Hinton)

How: every neuron computes w·x + b and then ReLU. The network has 60 million parameters and 650,000 neurons, all made of that one pattern.

Why this method: the old S-shaped curve flattens out for big inputs, which slows learning. ReLU's ramp never flattens for positive numbers, and in the paper's CIFAR-10 test it reached 25% training error six times faster than the S-curve version.

A smoother ReLU inside language models 🧠 LLMs · 2018 BERT (Google)

How: inside each transformer layer, vectors go through line → bend → line. BERT's paper says it uses the GELU bend (Hendrycks & Gimpel) rather than ReLU, following OpenAI's GPT. GELU looks like ReLU with the sharp corner rounded off.

Why this method: same job as ReLU (add the bend that stacked lines lack), but smooth, so small knob changes give small output changes everywhere.

Stacked pieces can fit any curve 🤖 Machine learning · 1989 Universal approximation theorem

How: proofs from 1988–1989 (Cybenko; Hornik, Stinchcombe & White) showed that one layer of enough bendy units, added up with the right strengths, can approximate any continuous curve as closely as you want. Later work (Leshno et al., 1993) showed this works for any bend that isn't a plain polynomial, ReLU included.

Why this method: it's the guarantee behind your ReLU builder: more pieces, closer fit. It says a good fit exists; training (Phase 3 and 7) is how you find it.

🤯 Fun fact · knobs were once real knobs

Rosenblatt's Mark I Perceptron machine stored its weights in potentiometers, the same kind of turnable knob as a volume control, and during learning the weights were updated by electric motors turning them. “Turning knobs to reduce error” was literal.

🌉 AI bridge · functions all the way down

Deep learning: a layer is many w·x + b's computed at once, which is a matrix multiplication (Lesson 2.2). The slope of a stack of functions comes from the chain rule (Lesson 3.2), and Lesson 8.3 builds a full network from exactly these pieces.

RL: deep RL agents use a neural network as their function from “what I see” to “how good each move is”. The RL course gives a 15-minute version of this lesson's ideas in Lesson 4.2: neural nets & gradient descent.

Check yourself

1. A neuron computes y = ReLU(3x − 6). What does it output for x = 1?
Inside first: 3 × 1 − 6 = −3. ReLU turns negatives into 0, so the output is 0. The neuron only switches on once 3x − 6 > 0, that is for x > 2.
2. g(x) = x + 1 and f(x) = 2x. What is f(g(3))?
Inside out: g(3) = 3 + 1 = 4, then f(4) = 2 × 4 = 8. Doing it the other way round, g(f(3)) = g(6) = 7. Order matters.
3. Why do neural networks put a bend like ReLU between their straight-line layers?
2(3x + 1) + 5 = 6x + 7: lines of lines are lines. Without bends, a 100-layer network could only ever draw a straight line. With them, it can build any shape, like your ReLU builder.
📝 TL;DR
  • A function is a machine: one input in, one output out. f(x) reads “f of x”.
  • y = wx + b: w = slope (change per +1 input), b = intercept (output at 0).
  • ReLU(x) = max(0, x): the bend used in most neural networks since AlexNet (2012).
  • f(g(x)) = do g, then f. Stacking lines gives a line; lines + bends can build any shape.
