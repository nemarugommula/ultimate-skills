Phase 0 · Recap

Recap: the language of math

Five tools, one page: functions, powers and logs, e and exp, and Σ/Π. With these you can already read the formulas at the heart of every LLM.

🧾 Cheat sheet

🗺️

0.1 Why math for AI

guess → loss → nudge knobs downhill

A model is a function with knobs; training turns the knobs to shrink the error.

Used in: every trained model, from a straight-line fit to GPT-3's 175B parameters.

⚙️

0.2 Functions

y = wx + b · ReLU(x) = max(0, x) · f(g(x))

Slope and intercept; a bend; machines in a row. Lines of lines are lines, so networks need bends.

Used in: every neuron and layer; ReLU since AlexNet (2012), GELU in BERT.

🔁

0.3 Exponents & logs

bm·bn = bm+n · log(a·b) = log a + log b

Logs turn × into +, so tiny products become normal-sized sums.

Used in: log-probabilities, the log-loss, scaling laws on log-log plots, log-transformed data.

🌱

0.4 e and exp

pi = ezi / Σj ezj · γt

e ≈ 2.718; exp makes any score positive and keeps order. Fixed-fraction shrinking is exponential decay.

Used in: softmax in every LLM, temperature, RL discounting, Adam's averages.

➕

0.5 Σ and Π

Σi=1n xi · Πi=1n pi · L = −(1/N) Σ ln pi

For-loops that add (start 0) or multiply (start 1). ln Π = Σ ln.

Used in: the GPT training goal, MSE, spam filters, RL returns, matrix multiplication.

🧩 Use it yourself: grade a tiny language model

A toy model reads “The cat sat on the mat” and makes three predictions. For each, here are its scores for three candidate words; the bold word is what really came next.

after…scores
“The”cat 2, dog 1, car 0
“The cat”sat 1, ran 1, flew −1
“The cat sat on the”mat 0, sofa 2, moon −2

Using only Phase 0: (a) turn each row into the probability of the correct word, (b) find the probability of all three being right, (c) compute the loss L = −(1/N) Σ ln pi, and (d) say which knob the model should turn first.

Solution worked out step by step

(a) Softmax each row (Lesson 0.4): e to every score, divide by the row's total.

  • Row 1: e² + e¹ + e⁰ = 7.389 + 2.718 + 1 = 11.107 → p(cat) = 7.389 / 11.107 = 0.665.
  • Row 2: e¹ + e¹ + e⁻¹ = 2.718 + 2.718 + 0.368 = 5.804 → p(sat) = 2.718 / 5.804 = 0.468.
  • Row 3: e⁰ + e² + e⁻² = 1 + 7.389 + 0.135 = 8.524 → p(mat) = 1 / 8.524 = 0.117.

(b) Π (Lesson 0.5): 0.665 × 0.468 × 0.117 ≈ 0.0365, about a 3.7% chance of getting all three right.

(c) Σ of logs, then average (Lessons 0.3 and 0.5): ln 0.665 + ln 0.468 + ln 0.117 ≈ −0.408 − 0.759 − 2.143 = −3.309. Check: ln 0.0365 ≈ −3.31 ✓. So L = −(1/3)(−3.309) ≈ 1.103.

(d) The biggest loss term is row 3 (−ln 0.117 = 2.143, about two thirds of the total): the model was confident in “sofa”. Training (Lesson 0.1) would mostly raise the “mat” score and lower “sofa” there. Note that adding the same number to all three scores in a row would change nothing: only differences matter.

🏆 Boss quiz

1. What is ReLU(−4) + ReLU(3)?
ReLU keeps positives and turns negatives into 0: 0 + 3 = 3 (Lesson 0.2).
2. What is log₂(32)?
“How many 2s multiply to make 32?” 2 × 2 × 2 × 2 × 2 = 32, so 5 (Lesson 0.3).
3. Which probability can softmax never give to an option, no matter how bad its score is?
escore is always positive, even for a score of −100, so every option keeps a sliver of probability. (Lesson 0.4).
4. What is Σi=13 (i + 1)?
Loop i = 1, 2, 3 and add i + 1: 2 + 3 + 4 = 9. (24 = 2 × 3 × 4 is the Π version.) Lesson 0.5.
5. GPT-1's training goal is written as Σ log P(token), not as Π P(token). Why?
ln Π p = Σ ln p (Lessons 0.3 and 0.5). The product of thousands of probabilities is too small for a computer; the sum of their logs is an ordinary number.
