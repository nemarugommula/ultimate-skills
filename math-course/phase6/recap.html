Phase 6 · Recap

Recap: information theory

Surprise, entropy, cross-entropy, KL and mutual information on one page, then spot them in real AI systems and use them on a real-looking problem.

🧾 Cheat sheet

😲

6.1 Surprise

−log₂ p bits

Rare = informative. Coin flip = 1 bit, certainty = 0, impossible = ∞. Surprises of independent events add. ln gives nats (1 nat ≈ 1.443 bits).

Used: per-token LLM loss, GLTR, Huffman codes.

🎲

6.2 Entropy

H(p) = −Σ p log₂ p

Average surprise = how hard to guess. 0 if certain, log₂ n if uniform. The floor for lossless compression.

Used: decision-tree splits, RL entropy bonus (A3C, SAC), semantic entropy.

📉

6.3 Cross-entropy

H(p, q) = −Σ p log q

Surprise when the truth is p but you believe q. One-hot target → −ln q(correct). Perplexity = eavg loss. Gradient wrt logits: q − p.

Used: LLM pretraining & SFT, classifiers, label smoothing, distillation.

🪢

6.4 KL divergence

DKL(p‖q) = Σ p log(p/q)

= H(p, q) − H(p): extra bits for the wrong belief. ≥ 0, = 0 iff equal, not symmetric. Forward covers, reverse seeks a mode.

Used: RLHF leash (β = 0.02 in InstructGPT), DPO, VAEs, TRPO.

🔗

6.5 Mutual information

I(X ; Y) = H(Y) − H(Y | X)

How much X tells you about Y. 0 if independent. = DKL(P(X,Y) ‖ P(X)P(Y)). InfoNCE: I ≥ ln N − loss.

Used: CLIP, SimCLR, feature selection, information gain.

🗣️ Teach it back (60 seconds)

Explain to a friend, using only the words “surprise” and “average”: why is an LLM's training loss −ln(probability of the right word)? What does a perplexity of 10 mean? And why does RLHF need a KL leash?

A good answer: surprise is −log p, the loss is the average surprise at the real text (cross-entropy), perplexity 10 = “as unsure as picking among 10 equally likely words”, and KL measures the extra surprise of the new model's habits compared with the original's, which RLHF charges for so the model doesn't drift into reward-model blind spots.

🧩 Use it yourself

🧩 Problem · did fine-tuning help, and how far did it drift?

You fine-tuned a small support chatbot. On a held-out reply of 4 tokens, the probabilities each model gave the real tokens were:

  • Base model: 0.5, 0.2, 0.1, 0.4
  • Fine-tuned model: 0.6, 0.4, 0.05, 0.5

On one prompt, the next-token distributions over three candidate tokens were: fine-tuned π = [0.8, 0.1, 0.1], base πref = [0.5, 0.3, 0.2].

Your tasks: (a) each model's average cross-entropy and perplexity on the reply; (b) which token got worse; (c) DKL(π ‖ πref) on the prompt, and the RLHF-style penalty with β = 0.02.

Reveal the worked solution

(a) Per-token losses are −ln p.

  • Base: 0.693, 1.609, 2.303, 0.916 → average 1.380 nats → perplexity e1.380 ≈ 3.98.
  • Fine-tuned: 0.511, 0.916, 2.996, 0.693 → average 1.279 nats → perplexity ≈ 3.59.

Lower is better: the fine-tuned model is less surprised by real replies (about 1.85 bits per token instead of 1.99).

(b) Token 3 went from 0.1 to 0.05: its loss rose from 2.303 to 2.996 nats. Cross-entropy averages hide this, so it's worth looking at the worst tokens too.

(c) DKL(π‖πref) = 0.8·ln(0.8/0.5) + 0.1·ln(0.1/0.3) + 0.1·ln(0.1/0.2) ≈ 0.376 − 0.110 − 0.069 = 0.197 nats. Penalty: 0.02 × 0.197 ≈ 0.0039 reward points for this token. Small, but it is charged at every token, and it grows quickly if π starts putting mass where πref had almost none.

🏆 Boss quiz

1. A training log shows a per-token loss of ln 8 ≈ 2.08 nats. What does that mean?
Perplexity = eloss = eln 8 = 8. In bits, ln 8 nats ÷ ln 2 = log₂ 8 = 3 bits: like guessing 3 coin flips per token.
2. Which distribution over 4 outcomes has the highest entropy?
Uniform is the hardest to guess: H = log₂ 4 = 2 bits, the maximum. A certain outcome has H = 0; [0.7, 0.1, 0.1, 0.1] is in between (about 1.36 bits).
3. Cross-entropy H(p, q) = 3.0 bits and entropy H(p) = 2.2 bits. What's DKL(p‖q)?
KL = cross-entropy − entropy = 3.0 − 2.2 = 0.8 extra bits. The reverse KL is a different number and isn't needed here.
4. A fresh model trains with label smoothing (ε = 0.1). Its training loss stops falling well above 0. Is something broken?
H(p, q) = H(p) + DKL(p‖q) ≥ H(p). With a one-hot target H(p) = 0, but a smoothed target spreads ε of its mass, so the best possible loss is its entropy (about 0.39 nats for 5 classes in Lesson 6.3).
5. In CLIP's training batch, why does winning the “which caption matches?” game mean the image and text embeddings share information?
The matching game is cross-entropy over the N × N similarity grid. Lower loss pushes up a guaranteed lower bound on mutual information, capped at ln N, which is why big batches help.
