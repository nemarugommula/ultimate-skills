Phase 8 · Lesson 3

A neural network, all the math

Matrix multiply, bend, repeat; then the chain rule backwards. That's the whole thing, from a 33-weight toy to the MLP blocks inside GPT-3.

🧰 You'll need (quick reminders)
  • A layer is a matrix: Wx gives one dot product per row of W (Lesson 2.2).
  • Backpropagation: the chain rule run backwards through a graph, multiplying local slopes (Lesson 3.5).
  • The output gradient of sigmoid or softmax + cross-entropy is just p − y (Lessons 8.1–8.2).
🎯 Hook

In 1969 Minsky and Papert's book Perceptrons pointed out that a single artificial neuron can't compute XOR (“one or the other, but not both”). Put the four cases on a plane and you'll see why: no straight line splits them. Lesson 8.1's ring had the same problem.

The fix is almost embarrassingly small: one hidden layer with a bend in it. You'll solve XOR by hand in a minute, then watch a network learn a spiral.

Numbers first: one layer

Input x = [1, 2]. A layer with 3 neurons has a 3 × 2 weight matrix and 3 biases. Each neuron does Lesson 8.1's dot product:

W = [[1, −1], [0.5, 1], [−2, 1]], b = [0, −1, 0.5]
Wx + b = [1−2+0, 0.5+2−1, −2+2+0.5] = [−1, 1.5, 0.5]  →  ReLU  →  [0, 1.5, 0.5]

The last step is the activation function. The most common one, ReLU, just replaces negatives with 0. Another classic, tanh, squashes everything smoothly into (−1, 1).

h = φ(Wx + b)     ReLU(z) = max(0, z) “The layer's output h is phi (the activation) applied, entry by entry, to W times x plus b.” ReLU reads “rectified linear unit”: keep positives, zero out negatives.

Why the bend is everything

Drop the activation and stack two layers: W₂(W₁x). Matrix multiplication can be regrouped, so that's (W₂W₁)x: one single matrix. With W₁ = [[1, 2], [0, 1]] and W₂ = [[1, 0], [3, 1]]:

x = [1, 1]:   W₁x = [3, 1],   W₂(W₁x) = [3, 10]  =  (W₂W₁)x = [[1, 2], [3, 7]]·[1, 1] = [3, 10] ✓

A hundred linear layers collapse into one linear layer, which still draws straight lines. The nonlinearity between layers is what stops the collapse.

💡 Big idea A neural network is matmul, bend, matmul, bend, …, then a softmax or sigmoid. Each layer moves and folds the space so that, by the last layer, a straight line (Lesson 8.1) is enough. Training is the chain rule run backwards, starting from p − y.
🧠 Analogy: folding paper before you cut

You may only make one straight cut with scissors. On a flat sheet, that's a straight line. Fold the sheet a few times first, then cut straight through all the layers, and unfold: the cut is now a zig-zag or even a closed shape. Each hidden layer is a fold. The final layer is the one straight cut.

With the solution weights, the two 🟢 points land on the same spot in hidden space, and the 🔴 points move apart: now a line splits them. Turn ReLU off and the four points end up on one straight line with 🟢 in the middle. No cut can do it: that's the collapse, live.

The forward and backward pass

Here's the full network we'll train below: 2 inputs, one hidden layer, one output probability.

z₁ = W₁x + b₁  →  h = φ(z₁)  →  z₂ = W₂h + b₂  →  p = σ(z₂)  →  L = cross-entropy(p, y) The forward pass: left to right, each arrow is one small function. Keep every intermediate number; the backward pass needs them.

The backward pass walks right to left. Each step is the chain rule (Lesson 3.2): “how the loss changes with this” = “how it changes with the next thing” × “how the next thing changes with this”. We write δ (“delta”) for the error signal arriving at a layer. Watch it on real numbers first:

✏️ Worked example: XOR forward and backward by hand

Weights: W₁ = [[1, 1], [1, 1]], b₁ = [0, −1], ReLU, then W₂ = [4, −8], b₂ = −2, sigmoid.

input xh = ReLU(W₁x + b₁)z₂ = 4h₁ − 8h₂ − 2p = σ(z₂)XOR
[0, 0][0, 0]−20.1190 ✓
[1, 0][1, 0]20.8811 ✓
[0, 1][1, 0]20.8811 ✓
[1, 1][2, 1]−20.1190 ✓

Backward pass for x = [1, 1] (target y = 0):

  • δ₂ = 0.119 − 0 = 0.119. Then ∇W₂ = 0.119 × h = 0.119 × [2, 1] = [0.238, 0.119].
  • Send it back: W₂ᵀδ₂ = [4, −8] × 0.119 = [0.477, −0.954]. Both hidden z's were positive (2 and 1), so ReLU′ = [1, 1] and δ₁ = [0.477, −0.954].
  • ∇W₁ = δ₁ xᵀ = [[0.477, 0.477], [−0.954, −0.954]]. Gradient descent subtracts these, which lowers z₂ for this input and pushes p further toward 0.

Those were the four backward rules. Here they are one per line:

δ₂ = p − y “The output error is the prediction minus the target”: Lesson 8.1's p − y. Above: 0.119 − 0 = 0.119.
∇W₂ = δ₂ hᵀ “The gradient for W₂ is δ₂ times h”: the error arriving at the layer's output × the input that layer multiplied. (ᵀ, “transposed”, just turns the column h into a row so the shapes match W₂.) Above: 0.119 × [2, 1].
δ₁ = (W₂ᵀδ₂) ⊙ φ′(z₁) “To send the error one layer back, run it backwards through the same wires (W₂ᵀ), then multiply element by element by the activation's slope φ′.” ⊙ means element-by-element multiply: [a, b] ⊙ [c, d] = [ac, bd]. ReLU's slope is 1 where z > 0 and 0 elsewhere. Above: [0.477, −0.954] ⊙ [1, 1].
∇W₁ = δ₁ xᵀ “The gradient for W₁ is δ₁ times x”: the same rule as for W₂, one layer down. Deeper networks just repeat the last two lines, layer after layer.

Counting parameters

A layer from din to dout numbers has din × dout weights plus dout biases. A 2 → 8 → 1 network: (2×8 + 8) + (8×1 + 1) = 24 + 9 = 33 numbers to learn.

The MLP block inside the original Transformer goes 512 → 2048 → 512: (512×2048 + 2048) + (2048×512 + 512) = 2,099,712. A rough rule for GPT-style models: each layer has about 4d² weights in attention (Lesson 8.4) and 8d² in the MLP (d → 4d → d), so 12 d² per layer. For GPT-3, with 96 layers and d = 12,288: 12 × 96 × 12,288² ≈ 174 billion. The paper says 175B: the small gap is the token-embedding table, the biases and other small pieces.

🐍 In code 
import numpy as np
x, y = np.array([1., 1.]), 0
W1, b1 = np.array([[1., 1.], [1., 1.]]), np.array([0., -1.])
W2, b2 = np.array([4., -8.]), -2.
z1 = W1 @ x + b1; h = np.maximum(0, z1)           # forward: matmul, bend
p = 1 / (1 + np.exp(-(W2 @ h + b2)))                # 0.119
d2 = p - y                                          # backward starts at p - y
gW2 = d2 * h; d1 = (W2 * d2) * (z1 > 0); gW1 = np.outer(d1, x)

import torch.nn as nn                                 # the same network, ready-made
net = nn.Sequential(nn.Linear(2, 8), nn.Tanh(), nn.Linear(8, 1))
sum(p.numel() for p in net.parameters())            # 33

🌍 Where it's used
The MLP block in every transformer layer 🧠 LLMs · 2017 Attention Is All You Need

How: after attention, each token's vector goes through FFN(x) = max(0, xW₁ + b₁)W₂ + b₂ (the paper writes x as a row, PyTorch-style, Lesson 2.2; in this course's column form it's W₂ max(0, W₁x + b₁) + b₂): exactly this lesson's matmul, ReLU, matmul, from 512 to 2,048 and back to 512 numbers.

Why this method: attention mixes information between tokens but is mostly a weighted average. The MLP adds the nonlinear processing within each token, and it holds most of each layer's weights (8d² of the 12d²).

A network that outputs action values 🎮 RL · 2013 DQN: Playing Atari with Deep RL

How: raw game pixels go through convolutional layers, a fully connected layer of 256 ReLU units, and an output layer with “a single output for each valid action”: the estimated future reward of pressing that button. See RL course 4.2.

Why this method: a table of values for every possible screen is impossible. A network generalizes from screens it has seen to ones it hasn't, and one forward pass scores every action at once.

Policy and value networks 🎮 RL · 2016 AlphaGo (Silver et al., Nature)

How: a “policy network” outputs a probability for every move (a softmax, Lesson 8.2) and a “value network” outputs one number: how likely this position is to win. Both are deep networks trained first on human games, then by reinforcement learning from self-play.

Why this method: the paper reports that even without lookahead search, the networks alone played at the level of strong Monte Carlo search programs. With search on top, AlphaGo beat the European champion 5–0.

🤯 Fun fact · one hidden layer is (in theory) enough

In 1989 George Cybenko proved that a network with a single hidden layer of sigmoid units can approximate any continuous function (on a bounded region) as closely as you like, given enough units. That's the “universal approximation theorem”. The catch is “enough units”: in practice, deeper networks need far fewer weights, which is why modern models are deep.

🌉 AI bridge · one recipe, every model

LLMs: a transformer layer = attention (next lesson) + this lesson's MLP. Stack 96 of them and add Lesson 8.2's softmax on top, and you have GPT-3.

Check yourself

1. How many parameters (weights + biases) does a 3 → 4 → 2 network have?
First layer: 3×4 weights + 4 biases = 16. Second: 4×2 + 2 = 10. Total 26. (20 forgets the biases.)
2. You remove every activation function from a 10-layer network. What can it still do?
W₁₀(…(W₂(W₁x))) = (W₁₀⋯W₂W₁)x, one matrix. You saw it in the XOR playground with ReLU off and in the trainer with “linear”.
3. DQN plays Atari with a neural network whose output layer has one number per joystick action. What do those numbers mean?
They are Q-values: a value function estimating future rewards (the paper's words). The agent presses the button with the biggest one. Lesson 8.6 shows the Bellman equation these values are trained to satisfy.
📝 TL;DR
  • A layer: h = φ(Wx + b). A network: layers stacked, then sigmoid/softmax.
  • Without φ, stacked layers collapse into one matrix: straight boundaries only.
  • Backward: δ = p − y at the top; ∇W = δ × input; send δ back with Wᵀ and φ′.
  • Parameters: din·dout + dout per layer; GPT-style ≈ 12 d² per layer (GPT-3 ≈ 174B).
  • Used as the MLP in every transformer, as DQN's Q-network and AlphaGo's policy/value nets.
