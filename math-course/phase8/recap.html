🧾 Phase 8 cheat sheet

8.1 Regression

p = σ(w·x + b), ∇ = (p − y)x

A dot product, squashed, trained by gradient descent. Straight-line boundary.

📍 ad clicks, medical risk scores, linear probes, scaling-law fits

8.1b Trees & boosting

Gain = H(parent) − Σ (nc/n)·H(child) · F ← F + η·h

Ask the question with the biggest gain; forests average trees, boosting adds small trees fit to the residuals (the negative gradient).

📍 XGBoost, LightGBM, Kinect body parts, tabular data

8.2 Softmax

p = ez/Σez, ∂L/∂z = p − y

Scores → probabilities; the cross-entropy gradient is a subtraction.

📍 image classifiers, LLM output over the vocabulary, RL policies

8.3 Neural network

h = φ(Wx + b), δ₁ = (W₂ᵀδ₂) ⊙ φ′

Matmul, bend, repeat; backprop sends p − y backwards. ≈ 12d² weights per GPT layer.

📍 transformer MLPs, DQN, AlphaGo's networks

8.3b Convolution

out[i,j] = Σ x[i+a, j+b]·w[a,b]

One small filter's dot product, reused at every position. Size ⌊(n+2p−k)/s⌋+1; params Cout(k²Cin+1).

📍 LeNet, ResNet, U-Net, ViT patch embedding

8.4 Attention

softmax(QKᵀ/√d)V

Every token's query scores every key; softmax weights mix the values. Causal mask for GPT.

📍 every LLM, ViT, the KV cache in serving

8.4b Diffusion

xt = √ᾱt x₀ + √(1−ᾱt) ε, loss ‖ε − εθ‖²

x = μ + Lz samples N(μ, Σ). Add noise, learn to guess it with MSE, then subtract the guesses step by step.

📍 Stable Diffusion, DALL·E 2, Diffusion Policy, VAEs

8.5 Numerics

log Σez = m + log Σez−m

Floats round, overflow, underflow. Subtract the max; quantize with q = round(w/s).

📍 mixed precision, bf16, LLM.int8(), QLoRA

8.6 RL math

V(s) = 𝔼[r + γV(s′)], ∇J = 𝔼[∇log π · G]

Values by one-step recursion; policies by the log-derivative trick.

📍 DQN, AlphaGo, RLHF, GRPO

🧩 Use it yourself: will it fit on my GPU?

🧩 The task

You want to run LLaMA-7B for a 4,096-token chat on a GPU with 24 GB of memory. The LLaMA paper lists the 7B model as 32 layers with d = 4,096 (32 heads) and 6.7B parameters. Using only this phase's math: (1) sanity-check the parameter count, (2) how much memory do the weights need in bf16, int8 and 4-bit, (3) how big is the KV cache for 4,096 tokens in 16-bit, (4) does it fit, and what about 4 chats at once?

Solution Worked out with 8.3, 8.4 and 8.5
  1. Parameters (8.3): 12 · L · d² = 12 × 32 × 4,096² = 6.44 billion. The paper's 6.7B is close; the rest is mostly the token-embedding and output tables.
  2. Weights (8.5): bf16 is 2 bytes per number: 6.7B × 2 = 13.4 GB. int8: 6.7 GB. 4-bit: 3.35 GB (plus a little for the scales).
  3. KV cache (8.4): per token, every layer stores a key and a value of d numbers: 2 × 32 × 4,096 × 2 bytes = 524,288 bytes ≈ 0.5 MB per token. For 4,096 tokens: about 2.15 GB.
  4. One chat in bf16: 13.4 + 2.15 ≈ 15.5 GB. Fits in 24 GB, with room for activations. Four chats: 13.4 + 4 × 2.15 ≈ 22 GB: too tight once activations are added. With 4-bit weights: 3.35 + 8.6 ≈ 12 GB, comfortable. Notice that in the 4-bit case the KV cache, not the weights, is now most of the memory. That's why serving systems like vLLM work so hard on it.
  5. And the last step (8.2 + 8.5): each generated token ends with a softmax over the vocabulary. Compute it in fp32 after subtracting the max logit, so a logit of 40 never becomes e40 = ∞ in fp16 (whose largest number is 65,504; bf16 would hold e40 ≈ 2.4 × 10¹⁷, but with only 2–3 digits).

🏆 Boss quiz: the whole course

1. (Phases 1 + 8) A query q = [1, 2] meets a key k = [3, 1], and dk = 4. What is the scaled attention score?
Dot product 1×3 + 2×1 = 5 (Lesson 1.3), divided by √4 = 2 gives 2.5 (Lesson 8.4). Softmax over all the keys' scores comes next.
2. (Phases 3 + 8) A classifier outputs p = [0.1, 0.6, 0.3] and the true class is the first one. What gradient reaches the logits?
p − y with y = [1, 0, 0]. Backpropagation (Lesson 3.5) carries this into every weight of the network (Lesson 8.3).
3. (Phase 6) An LLM gave the real next token a probability of 0.25. What is its cross-entropy loss on that token, in bits?
−log₂ 0.25 = 2: as surprising as two fair coin flips both landing heads. Average this over all tokens and you have the training loss (Lesson 6.3).
4. (Phase 5) Your model scores 99% on its training data and 70% on new data. What's the most likely story?
A big train–test gap is the signature of overfitting (Lesson 5.6). Remedies: more data, a smaller model, or regularization like weight decay and dropout (Lesson 7.4).
5. (Phases 4 + 8) GRPO scores 8 answers to the same math problem and subtracts their average reward before the policy-gradient update. Why?
Subtracting a baseline leaves the average direction of the gradient (almost) unchanged but cuts its noise, its variance (Lessons 4.4 and 8.6). The group average is a free, critic-less baseline.
