# Math for AI 📐🎲🧠

An interactive, visual course on the math behind machine learning, deep learning, LLMs, reinforcement learning and data science. Built for beginners: intuition first, no proofs, and every idea tied to exactly where it's used in real AI systems.

Sibling of `../rl-course`: same design, and the 🌉 bridge boxes link into the RL lessons that use each idea.

## Start

Open `index.html` in a browser (double-click works). Or serve both courses together so the cross-links work:

```bash
cd ~ && python3 -m http.server 8766
# open http://localhost:8766/math-course/
```

Stuck on a term or symbol? `glossary.html` reads every symbol out loud and links each term to the lesson that teaches it. `review.html` brings old quiz questions back on a spaced-repetition schedule.

Progress (completed lessons and quiz answers) is saved in your browser's localStorage, separately for `file://` and `localhost`. Use **Export / Import progress** on the home page to move it.

## Labs

```bash
cd ~/math-course/labs
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 phase1_vectors.py   # or run cell by cell in your editor (# %% cells)
```

Each TODO has ✅ self-checks right after it. Solutions are in `labs/solutions/`. All labs need only NumPy and matplotlib and run in seconds.

## Structure

```
index.html          home + roadmap (rendered from COURSE in assets/course.js)
assets/style.css    design system (callout boxes, color language, playgrounds)
assets/course.js    course manifest, nav/sidebar, progress, quizzes, MX math helpers
assets/plot.js      tiny canvas charts (line, bars)
assets/plane.js     2D coordinate plane with draggable vectors/points, curves and heatmaps
glossary.html       searchable glossary, symbols read aloud
review.html         spaced-repetition review of every lesson quiz
assets/review-bank.js  generated by tools/build-review-bank.py (rerun after editing quizzes)
phase0/ … phase8/   lessons (one HTML file each) + recap.html (cheat sheet + lab)
labs/               Python labs with TODOs; labs/solutions/ has answers
tools/              headless page test harness, review-bank builder
```

| Phase | Topic |
|---|---|
| 0 | The language of math: functions, exponents & logs, e, Σ and Π |
| 1 | Vectors & embeddings: dot product, cosine similarity, norms |
| 2 | Matrices: transformations, matmul, tensors, rank, eigenvectors, SVD/PCA |
| 3 | Calculus: derivatives, chain rule, gradients, gradient descent, Taylor & curvature, backprop, integrals |
| 4 | Probability: Bayes, distributions, expectation, chain rule, sampling & temperature, importance sampling, CLT |
| 5 | Statistics & data science: k-means, MLE, Bayesian thinking, A/B tests, overfitting, precision/recall & calibration |
| 6 | Information theory: surprise, entropy, cross-entropy, KL, mutual information |
| 7 | Optimization: loss landscapes, SGD, Adam, regularization, constraints |
| 8 | Putting it together: regression, trees & boosting, softmax, neural nets, convolution, attention, diffusion, floats, the math of RL |
