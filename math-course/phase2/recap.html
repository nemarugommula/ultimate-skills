Recap: matrices & transformations

Six lessons, one picture: a matrix is a machine that moves space. Here's everything on one page, a game to spot it in real AI systems, one realistic problem and the boss quiz.

🧾 Cheat sheet

🧮

2.1 Matrices move space

Ax = x₁·col₁ + x₂·col₂

Columns = where [1, 0] and [0, 1] land. Rotation R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]] keeps lengths.

🌍 image flips & rotations, every layer, RoPE in LLMs

✖️

2.2 Matrix multiplication

Yij = row i of W · column j of X

(m×n)(n×p) → (m×p), about 2·m·n·p operations. AB = “do B, then A”; order matters.

🌍 dense layers y = Wx + b, ≈ 2 × params per token, attention QKᵀ

📦

2.3 Tensors & broadcasting

(N, C, H, W) · (batch, seq, d_model)

Reshape keeps the count. Broadcasting: align shapes from the right; sizes must match or be 1.

🌍 PyTorch/NumPy code, splitting attention heads, bias on a batch

🪶

2.4 Inverse & rank

det = ad − bc  ·  d² vs 2·d·r

det = area scale; 0 means squashed, no inverse. Rank = independent directions that survive.

🌍 LoRA, normal equations of regression, image compression

🧭

2.5 Eigenvectors

Av = λv

Directions only stretched, never turned. Power iteration finds the top one; |λ| > 1 explodes, < 1 vanishes.

🌍 PageRank, Markov steady states, RNN gradients

🔭

2.6 SVD & PCA

A = U Σ Vᵀ

Rotate or flip · stretch · rotate or flip. Top k layers = best rank-k copy. PCA = directions of most spread.

🌍 plotting embeddings, eigenfaces, compression, hidden topics (LSA)

🗣️ Teach it back

Explain to a friend in two minutes, without equations: “What does a neural-network layer do to a list of numbers, and why can LoRA fine-tune it so cheaply?”

A good answer mentions: the layer is a matrix that moves the input to a new spot (each output = one row dotted with the input); a matrix can be stored as two thin matrices when its changes only use a few directions (low rank); and that's why training only B and A is enough. 🧩 Use it yourself: a LoRA budget

✏️ The task

You want to fine-tune a model with 32 layers. Each layer has 4 attention weight matrices (query, key, value, output), each 4,096 × 4,096. You'll add a LoRA adapter of rank r = 16 to all of them. Work out, using only this phase's math:

  1. How many numbers are in those 128 big matrices?
  2. How many numbers will LoRA train, and what fraction is that?
  3. Do the shapes of B and A fit, so BA can be added to W?
  4. How much extra compute does one adapter add per token, compared with its big matrix?
Reveal Worked solution
  1. Full size: 32 layers × 4 matrices × 4,096² = 32 × 4 × 16,777,216 = 2,147,483,648 numbers (about 2.1 billion).
  2. LoRA: each adapter has B (4,096 × 16) and A (16 × 4,096): 2 × 4,096 × 16 = 131,072 numbers. Times 128 adapters = 16,777,216 (about 16.8 million). That's 2,147,483,648 / 16,777,216 = 128× fewer, about 0.78% (Lesson 2.4).
  3. Shapes: (4,096 × 16)·(16 × 4,096) → 4,096 × 4,096 ✓. The inside 16s match and the outside sizes equal W's, so W + BA is a valid sum (Lesson 2.2). Its rank is at most 16.
  4. Compute: the big matrix costs 2 × 4,096 × 4,096 = 33,554,432 operations per token (Lesson 2.2). The adapter does A·x first (2 × 16 × 4,096 = 131,072), then B·(Ax) (another 131,072): 262,144, which is 0.78% extra. After training you can merge BA into W, making the extra cost zero.

Note the order in step 4: computing B·(A·x) is cheap, but building the full BA first would cost far more. Same answer, different work, because B(Ax) = (BA)x lets you choose the order of the multiplications.

🏆 Boss quiz

1. The matrix [[0, −1], [1, 0]] (rows) rotates by 90°. Where does it send [2, 1]?
Rows: [0·2 + (−1)·1, 1·2 + 0·1] = [−1, 2]. Column view: 2·[0, 1] + 1·[−1, 0] = [−1, 2]. Its length is still √5, as a rotation should keep it (Lesson 2.1).
2. What shape is (16, 1, 5) + (3, 1)?
Align from the right: 5 vs 1 → 5; 1 vs 3 → 3; 16 vs missing → 16. Every size-1 axis stretches (Lesson 2.3).
3. A = [[2, 4], [1, 2]]. Which is true?
The columns [2, 1] and [4, 2] are dependent (the second is 2× the first). Zero area, information lost, nothing to undo (Lesson 2.4).
4. You multiply a random starting vector by the same matrix 100 times (power iteration). Where does its direction end up?
Each multiplication grows the part along the top eigenvector fastest, so it ends up dominating. That's how PageRank and Markov steady states are computed (Lesson 2.5). (A pure rotation, with no real eigenvectors, is the exception.)
5. A dataset's covariance matrix has eigenvalues 8 and 2. What share of the spread does PC1 keep, and where is PCA used in AI?
8 / (8 + 2) = 0.8. The word2vec paper and Google's Embedding Projector use PCA to draw high-dimensional embeddings on a flat screen (Lesson 2.6).
🌉 What's next · Phase 3: calculus

You now know what a network computes: matrices moving vectors, layer after layer. Phase 3 asks how it learns: which way to nudge each of those millions of matrix entries to make the loss smaller.

You'll meet the derivative (how much the output changes when you nudge an input), the gradient (a vector of those nudges, one per weight), and backpropagation, which passes gradients backwards through the same matrix multiplications you've learned here. Start with Lesson 3.1: derivatives.
