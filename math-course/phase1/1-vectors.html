Vectors: arrows and lists of numbers

A vector is a list of numbers that you can also draw as an arrow. It's how every AI model sees the world: houses, photos, words and game states all become vectors.

🧰 You'll need (quick reminders)
  • Square root: √25 = 5, because 5 × 5 = 25. And 3² (“3 squared”) means 3 × 3 = 9.
  • A function is a machine: numbers in, a number out (Lesson 0.2). AI models are functions, and their inputs are vectors.
🎯 Hook

A neural network can tell a handwritten 7 from a 1. A chatbot knows that “cat” is closer to “kitten” than to “car”. A robot keeps a pole balanced on a cart. Three very different jobs, but the model inside each one sees exactly the same kind of thing: a list of numbers.

A picture of a digit is 784 numbers. A word inside the smallest GPT-2 is 768 numbers. The pole on the cart is 4 numbers. By the end of this lesson you'll know why “list of numbers” and “arrow” are the same idea, and how to measure an arrow's length.

Numbers first: describe a house

A real-estate website wants to guess house prices. It describes each house with three numbers, always in the same order: size in m², number of bedrooms, age in years.

house A = [120, 3, 15]    house B = [65, 1, 40]

That's a vector: an ordered list of numbers. Each slot is called a component (or entry, or feature). The number of slots is the vector's dimension. These houses are 3-dimensional vectors. The order matters: [3, 120, 15] would be a 3 m² house with 120 bedrooms.

x = [x₁, x₂, …, xn] Read “x is the list x-one, x-two, up to x-n”. The little number underneath (a subscript) is just the slot number. n is how many slots there are: the dimension.

Mathematicians often write it standing up, like 120315. Same thing, different layout. In code it's simply a list or a NumPy array.

💡 Big idea A vector is two things at once: a list of numbers (what the computer stores) and an arrow or a point in space (what you can picture). Every tool in this phase works on both views, and AI uses both all the time.

The same list, drawn as an arrow

Take a 2-number vector, [3, 4]. Read it as directions from the origin (the point [0, 0]): go 3 to the right, then 4 up. Draw an arrow from the start to where you land. That arrow is the vector.

Negative numbers just flip the direction: [−2, 1] means 2 to the left, 1 up. Three numbers need a 3D room (right, up, forward). 768 numbers need a space you can't picture, but the arithmetic is exactly the same.

🧠 Analogy: treasure-map directions

“From the old oak, walk 3 steps east and 4 steps north.” That instruction is the vector [3, 4]. You can write it down as two numbers (the list view) or draw it on the map as one arrow (the arrow view). Same treasure either way.

How long is the arrow? Pythagoras

The arrow [3, 4] makes a right triangle: 3 along the bottom, 4 up the side, and the arrow is the slanted side. Pythagoras says: square the two sides, add, take the square root.

√(3² + 4²) = √(9 + 16) = √25 = 5

This length has its own symbol, two pairs of bars around the vector:

‖x‖ = √( x₁² + x₂² + … + xn² ) Read “the length of x” (also called the norm of x): square every component, add them all up, then take the square root.

It works in any number of dimensions. In 3D, ‖[2, 3, 6]‖ = √(4 + 9 + 36) = √49 = 7. In 768 dimensions you just have 768 squares to add. Lesson 1.4 shows other ways to measure length that AI also uses.

🎮 Playground · Drag the arrow

Drag the tip of the blue arrow. Watch the list and the length update. The dashed lines are the two sides of the right triangle; the dotted circle shows every tip with the same length. Can you find another arrow, besides [3, 4], with length exactly 5?

[3, 4] and [−4, 3] point in very different directions but have the same length, 5. A vector carries two pieces of information: a direction and a length. Keep that in mind; Lesson 1.3 compares directions and Lesson 1.4 compares lengths.

✏️ Worked example: three lengths by hand
  • [6, 8]: √(36 + 64) = √100 = 10. (It's [3, 4] doubled, so the length doubles too.)
  • [1, 2, 2]: √(1 + 4 + 4) = √9 = 3. Three dimensions, same recipe.
  • [−5, 12]: √(25 + 144) = √169 = 13. Squaring makes the minus sign disappear, so lengths are never negative.

Everything is a vector: colors and images

Your screen makes every color from three lights: red, green and blue, each from 0 (off) to 255 (full). So a color is a 3D vector [R, G, B]. Pure red is [255, 0, 0]. Yellow is [255, 255, 0]: red and green light together.

A photo is just a lot of these. A grayscale image needs one brightness number per pixel. Here's a tiny 3×3 image of a vertical line (0 = black, 255 = white), read row by row into one list:

→ [0, 255, 0, 0, 255, 0, 0, 255, 0]: a 9-dimensional vector

The famous MNIST digits are 28 × 28 pixels, so each one is a vector of 28 × 28 = 784 numbers. A 28 × 28 color image would be 28 × 28 × 3 = 2,352 numbers. Turning a grid into one long list like this is called flattening.

Math refresher Why Pythagoras works in 3D too

For [2, 3, 6]: first walk along the floor, 2 right and 3 forward. That floor distance is √(4 + 9) = √13. Now go 6 up. The floor distance and the height make a new right triangle, so the total is √(13 + 36) = √49 = 7. The middle square root cancels out, which is why you can simply add all the squares at once. Every extra dimension is one more right triangle.

🐍 In code 
import numpy as np
x = np.array([3, 4])
x.shape                     # (2,)  the dimension: 2 numbers
np.sqrt(np.sum(x ** 2))      # 5.0  square, add, square root
np.linalg.norm(x)           # 5.0  the same thing, built in

image = np.zeros((28, 28))     # a blank 28x28 grayscale picture
image.flatten().shape       # (784,)  one long vector

🌍 Where it's used
Feature vectors in tabular data 📊 Data science · 1990 California housing (scikit-learn)

How: a classic teaching dataset built from the 1990 US census. Each of its 20,640 rows is one neighborhood described by the same 8 numbers (median income, house age, average rooms, location…). Each row is an 8-dimensional feature vector, and a model maps it to a price guess.

Why this method: models need every example in the same fixed format. Putting each feature in its own agreed slot turns “a house” into something a function can take as input.

An image is one long vector 🖼️ Deep learning · 1998 MNIST handwritten digits

How: 60,000 training and 10,000 test images of digits, each 28 × 28 pixels. Flatten one and you get a 784-dimensional vector: a classic first dataset for training a neural network.

Why this method: flattening lets the simplest models (logistic regression, a basic neural network) read any image as numbers in fixed slots. Image networks like CNNs keep the grid shape instead, as a tensor (Lesson 2.3), but it's still numbers in slots.

A game state is a vector 🎮 RL · 1983 CartPole (Gymnasium docs)

How: the classic balancing task from Barto, Sutton and Anderson. The agent never sees a picture. It sees 4 numbers: [cart position, cart velocity, pole angle, pole angular velocity], and chooses to push left or right.

Why this method: those 4 numbers are everything needed to predict what happens next. A small vector is far easier to learn from than raw pixels of the same scene.

Every word is a vector inside an LLM 🧠 LLMs · 2019 GPT-2 config (n_embd = 768)

How: GPT-2 knows 50,257 tokens (words or word pieces). The smallest version's first step looks up each token's own vector of 768 numbers, and everything after that is arithmetic on vectors.

Why this method: a word's ID number (like 9246) says nothing about its meaning. A learned vector can place similar words near each other in space (Lesson 1.5).

🤯 Fun fact · sixteen million arrows

With 256 choices for each of R, G and B, your screen can show 256 × 256 × 256 = 16,777,216 colors. Every one of them is a point inside a cube, and the longest arrow in that cube is white, [255, 255, 255], with length √(3 × 255²) ≈ 441.7. Black, [0, 0, 0], is the only arrow with length 0.

Check yourself

1. What is the length ‖x‖ of the vector x = [6, 8]?
√(6² + 8²) = √(36 + 64) = √100 = 10. 14 is just 6 + 8 (that's a different kind of length, Lesson 1.4), and 100 is what you have before the square root.
2. A model reads 28 × 28 grayscale digit images as flat vectors. What is the dimension of each vector?
One number per pixel: 28 rows × 28 columns = 784 numbers. That's exactly how MNIST digits are fed to a simple neural network.
3. Why does an RL agent playing CartPole get the state as [cart position, cart velocity, pole angle, pole angular velocity], always in that order?
Order is part of a vector's meaning. [120, 3, 15] and [3, 120, 15] are different houses. Vectors can have any dimension: 3, 784, 768, or 12,288.
📝 TL;DR
  • A vector is an ordered list of numbers (its components). The number of components is its dimension.
  • The same vector is an arrow from the origin: [3, 4] = 3 right, 4 up.
  • Length by Pythagoras: ‖x‖ = √(sum of squares). ‖[3, 4]‖ = 5, in any dimension.
  • Houses, colors, images (MNIST: 784), game states (CartPole: 4) and words (GPT-2: 768) all become vectors.
