Phase 1 · Recap

Recap: vectors & embeddings

Five ideas, one picture: things become lists of numbers, and then meaning becomes geometry you can add, compare and measure.

🧾 Cheat sheet

➡️

1.1 Vectors

x = [3, 4]   ‖x‖ = √(3² + 4²) = 5

A list of numbers and an arrow at once. Length by Pythagoras.

Used: feature rows, MNIST (784 numbers), CartPole state (4), GPT-2 tokens (768).

➕

1.2 Adding & scaling

a + b, c · a, w ← w − ηg

Slot by slot. a − b is the arrow from b to a; averages are linear combinations.

Used: king − man + woman, mean pooling, steering vectors, every training step.

🎯

1.3 Dot product & cosine

x · w = Σ xiwi = ‖x‖‖w‖ cos θ

Multiply matching slots, add up. Cosine divides out the lengths: same direction = +1.

Used: every neuron, attention (query · key), semantic search, recommenders, CLIP.

📐

1.4 Norms & distance

‖x‖₁ = Σ|xi|   d(a, b) = ‖a − b‖

L2 = crow, L1 = taxi, L∞ = chess king. Normalize: x / ‖x‖ has length 1.

Used: k-NN, MSE, lasso (L1 → zeros), gradient clipping, RMSNorm.

🗺️

1.5 Embeddings

cat ← cat + 0.1·(dog − cat)

Learned dense vectors: things that appear together get pulled together, so similar = close.

Used: LLM token tables, RAG vector search, YouTube recommendations, t-SNE maps.

🧩 Use it yourself: a tiny movie recommender

Describe each movie with 3 numbers: [action, romance, comedy], each 0–5. A user loved Space Battle [5, 1, 1] and Robot Heist [4, 0, 2]. Which of these should you recommend next?

Laser Cops [5, 0, 3] · Love in Paris [0, 5, 1] · Funny Farm [1, 1, 5] · Galaxy Romance [3, 4, 1]

Use only Phase 1 math: build a taste vector, then compare it to every candidate.

Solution Worked out step by step

1. Taste vector = the average of what they loved (Lesson 1.2): ([5, 1, 1] + [4, 0, 2]) / 2 = [9, 1, 3] / 2 = [4.5, 0.5, 1.5]. Its length (Lesson 1.1): √(20.25 + 0.25 + 2.25) = √22.75 ≈ 4.77.

2. Cosine similarity with each candidate (Lesson 1.3):

🏆 Boss quiz

1. What is the length ‖x‖ of x = [2, 6, 9]?
√(4 + 36 + 81) = √121 = 11. 17 is the L1 norm (2 + 6 + 9), and 121 is before the square root.
2. Three word vectors in a sentence are [1, 4], [3, 0] and [5, 2]. What is their mean-pooled sentence vector?
Add slot by slot: [9, 6]. Then scale by 1/3: [3, 2]. [9, 6] forgot to divide; a single number would be a dot product, not an average.
3. Two embeddings are already normalized: a = [0.6, 0.8] and b = [0.8, 0.6]. What is their cosine similarity?
Both have length 1, so the cosine is just the dot product: 0.6 × 0.8 + 0.8 × 0.6 = 0.48 + 0.48 = 0.96. That's why vector databases normalize first.
4. What are the L1 and L2 distances between [1, 1] and [4, 5]?
The difference is [3, 4]. L1 (taxi) = 3 + 4 = 7; L2 (crow) = √(9 + 16) = 5. L1 is never smaller than L2.
5. Why do LLMs represent tokens with learned 768-number (or bigger) embeddings instead of one-hot vectors?
Any two different one-hot vectors have dot product 0 and distance √2. A learned table (one row per token) gives short vectors whose geometry carries meaning, and nobody writes them by hand: training pulls related tokens together.
🌉 What's next · Phase 2: matrices

Stack many vectors as the rows of a grid and you have a matrix. Multiply a matrix by a vector and you get many dot products at once: that's a whole neural-network layer (Lesson 2.2). An embedding table is a matrix too, and looking up a token is the same as multiplying it by a one-hot vector. Phase 2 shows how matrices move space, and how SVD and PCA find the directions that matter most.
