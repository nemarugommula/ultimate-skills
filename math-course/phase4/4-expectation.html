Expectation & variance

The average you'd get in the long run, and how wildly single results swing around it. Training minimizes an expected loss; RL maximizes an expected return; variance is the noise both fight.

🧰 You'll need (quick reminders)
  • A distribution lists every possible value of a random variable and its probability; they add up to 1 (Lesson 4.3).
  • Σ means “add these up” (Lesson 0.5). The mean is the sum divided by how many.
🎯 Hook

At an American roulette table you can bet $1 on red (you win about half the time) or $1 on the single number 17 (you win 1 time in 38, but you get $35). Which bet is better?

On average, they're exactly the same: both lose 5.26 cents per dollar. What's different is how much they swing. That's the difference between expectation and variance, and the same two numbers decide how fast a neural network or an RL agent can learn.

Numbers first: a probability-weighted average

A raffle sells 1,000 tickets. One ticket wins $500, ten tickets win $50, the rest win nothing. What's a ticket worth, on average?

$500 × 1/1000  +  $50 × 10/1000  +  $0 × 989/1000  =  $0.50 + $0.50 + $0  =  $1.00

If the ticket costs $2, you lose $1 per ticket on average. That's the expected value: multiply every possible outcome by its probability and add them up. It's a weighted average where the weights are probabilities (just like the dot product of Lesson 1.3, with values · probabilities).

𝔼[X] = Σx x · P(x) 𝔼 is read “the expected value of” (a fancy E). “The expected value of X is: for every possible value x, multiply x by its probability, then add everything up.”
x: an outcome (a payout, a loss, a reward)P(x): how likely it is
💡 Big idea The expected value is the long-run average. You'll almost never get exactly 𝔼[X] on a single try (no raffle ticket pays $1.00), but average many tries and you'll land very close to it (Lesson 4.7 says how close).

Variance: how much results swing

Two games can have the same 𝔼 and feel totally different. Game A: you always win exactly $1. Game B: 1% of the time you win $100, otherwise $0. Both have 𝔼 = $1. But B is mostly disappointment with the occasional jackpot.

To measure the swing, look at how far each outcome is from the average, square it (so misses on both sides count as positive), and take the expected value of that:

Var(X) = 𝔼[(X − μ)²]     σ = √Var(X) “The variance of X is the expected squared distance from the mean μ (mu).” Var is read “variance”. Its square root σ (sigma), the standard deviation, is back in the original units: a typical miss, in dollars.

Game B: the outcome $100 is 99 away from the mean (99² = 9,801) with probability 0.01, and $0 is 1 away (1² = 1) with probability 0.99. Var = 0.01 × 9,801 + 0.99 × 1 = 99, so σ ≈ $9.95. Game A: never misses, so Var = 0 and σ = 0.

✏️ Worked example: one die, by hand
  • 𝔼[X] = 1·⅙ + 2·⅙ + 3·⅙ + 4·⅙ + 5·⅙ + 6·⅙ = 21/6 = 3.5. (You can never roll 3.5, yet that's the long-run average.)
  • Distances from 3.5: −2.5, −1.5, −0.5, 0.5, 1.5, 2.5. Squared: 6.25, 2.25, 0.25, 0.25, 2.25, 6.25.
  • Var = (6.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25) / 6 = 17.5 / 6 ≈ 2.92, so σ = √2.92 ≈ 1.71.
  • Roulette, $1 on red: 18 of 38 slots win $1, 20 lose $1. 𝔼 = (18 − 20)/38 = −$0.053, σ ≈ $1.00. On the single number: 𝔼 = (35 − 37)/38 = −$0.053 too, but σ ≈ $5.76.
🧠 Analogy: two commutes

Route A always takes 30 minutes. Route B takes 20 minutes most days, but once a week a traffic jam makes it 70. Both average 30 minutes (expected value). Route B has a huge variance. If you have a flight to catch, you care about the variance, not just the average. A learning algorithm is like that too: same average direction, but a noisy estimate makes it wobble and need many more steps.

🎮 Playground · Same mean, different variance

20 players play game A (always $1, green) and 20 play game B (1% chance of $100, purple), for the same number of rounds. Each line is one player's total winnings. Both games have 𝔼 = $1 per round. Look at the spread.

After 100 rounds every A player has exactly $100. B players range from $0 to $300 or more, though their average is still close to $100. Theory says the spread of a total grows like σ × √n: for B that's 9.95 × 10 ≈ $99.5 after 100 rounds.

🐍 In code 
import numpy as np
x = np.array([1, 2, 3, 4, 5, 6]); p = np.full(6, 1/6)
E   = np.sum(x * p)                # 3.5   (same as x @ p, a dot product)
Var = np.sum((x - E)**2 * p)       # 2.92
np.sqrt(Var)                       # 1.71  standard deviation σ

# Estimate 𝔼 by averaging samples: the long-run view
rolls = np.random.randint(1, 7, size=100_000)
rolls.mean(), rolls.std()          # ≈ 3.5, ≈ 1.71

🌍 Where it's used
Training minimizes the expected loss 🤖 Machine learning · classic Empirical risk minimization

How: what we really want is a small expected loss, 𝔼[loss] over every example the model could ever see (the “true risk”). We can't compute that, so we minimize the average loss over the training data, a sample-based estimate of the expectation.

Why this method: the true distribution of data is unknown; an average over many real examples is the best available stand-in, and by the law of large numbers (Lesson 4.7) it gets closer with more data.

Expected return: what an RL agent maximizes 🎮 RL · 2018 Sutton & Barto: Reinforcement Learning, 2nd ed.

How: the same policy gets different total rewards on different runs (slippery floors, random opponents). So the goal is the expected return: the probability-weighted average over all the ways an episode could go. A value V(s) is exactly an expected return from state s.

Why this method: maximizing one lucky run would reward gambling. The expectation rewards what works on average, run after run.

Baselines reduce variance in policy gradients 🎮 RL · 1992 Williams: REINFORCE

How: a policy-gradient update pushes up actions in proportion to their return. Subtracting a baseline (“the usual return here”) leaves the expected update unchanged but removes a big shared swing, so the variance drops and learning needs fewer episodes.

Why this method: you can't change the expectation without biasing the algorithm, but you can cut the noise for free. Same mean, smaller variance: game B turned into something closer to game A.

🤯 Fun fact · the casino's only number

On an American wheel, betting $1 on red or $1 on a single number both have 𝔼 = −$0.0526 (a 5.26% house edge, Wikipedia: Roulette). A player can choose how much variance to take, but not the expectation. Over millions of bets, the casino earns almost exactly that 5.26%.

🌉 AI bridge · 𝔼 and Var in every training loop

Deep learning: the batch loss estimates an expected loss; the batch gradient estimates an expected gradient, with variance that shrinks as batches grow (Lesson 7.2).

RL: the return G is a random variable and the agent maximizes 𝔼[G]: RL Lesson 0.3: rewards, returns & discounting. Cutting its variance with a baseline is RL Lesson 5.3: baselines & the advantage.

Check yourself

1. A game pays $10 with probability 0.2, $1 with probability 0.5, and $0 otherwise. What's its expected value?
10 × 0.2 + 1 × 0.5 + 0 × 0.3 = 2 + 0.5 + 0 = 2.5. A plain average of the payouts ignores their probabilities; 𝔼 weights each by how often it happens.
2. Bets A and B both have 𝔼 = $1. A has σ = $0.10, B has σ = $10. Which statement is true?
Same expected value means the same long-run average. Standard deviation measures the swing of one result around it. B is riskier, not richer.
3. Why do policy-gradient methods subtract a baseline from the return?
The baseline doesn't change 𝔼 of the update (so no bias), it just removes a shared swing. Less variance means fewer episodes to learn the right direction.
📝 TL;DR
  • 𝔼[X] = Σ x·P(x): the probability-weighted, long-run average.
  • Var(X) = 𝔼[(X − μ)²]: expected squared miss. σ = √Var: a typical miss, in the original units.
  • Same mean ≠ same experience: variance is the risk, the noise, the wobble.
  • In AI: expected loss (training), expected return (RL), baselines and big batches to cut variance.
