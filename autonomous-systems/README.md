# Autonomous Systems 🚗🛸🤖

An interactive, visual course on the **foundations of autonomous vehicles, drones and mobile robots**, for software engineers new to robotics: how a machine perceives 3D space, knows where it is, predicts what others will do, plans a path and controls itself. Every topic shows how **Tesla** (camera-only, end-to-end neural), **Waymo** (lidar + radar + cameras, HD maps, modular plus learned) and **autonomous drones** (Skydio, PX4, ArduPilot) actually apply it, and why they chose differently.

Every lesson opens with a puzzle, asks you to predict before it reveals, and has playgrounds you can break (all offline, plain JavaScript): drive a car through a GPS-dead tunnel, localize a kidnapped robot with particles, fill an occupancy grid from lidar, run A* and RRT on a map you draw, tune a wobbling drone. A **🤔 Why this?** box explains every method from the problem it solved to what replaced it, and a **🚗 How Tesla / Waymo / drones do it** box ties it to the real systems, from their own docs, papers and talks. Company facts were checked against primary sources as of late 2026 and are dated in the text.

Sibling of `../math-course` (formulas link there), `../rl-course` (imitation and model-based learning), `../deep-learning` (neural-network internals), `../machine-learning`, `../ai-engineer` and `../system-design-course`: same design system.

## Start

Open `index.html` in a browser (double-click works). Or serve it:

```bash
cd ~/autonomous-systems && python3 -m http.server 8773
# open http://localhost:8773
```

Progress is saved in your browser's localStorage (keys start with `ascourse.`), separately for `file://` and `localhost`; use **Export / Import progress** on the home page to move it. `review.html` brings old quiz questions back on a spaced-repetition schedule; `glossary.html` explains every term, acronym, sensor and tool.

## Phases

| Phase | Topic | Lessons | Lab |
|---|---|---|---|
| 0 | **The autonomy loop**: sense → perceive → localize → predict → plan → control; SAE levels; the stack; modular vs end-to-end; Tesla vs Waymo vs drones; the long tail | 6 + recap | `phase0_loop.py` |
| 1 | **Spatial math**: coordinate frames, rotation matrices, Euler angles and gimbal lock, quaternions, homogeneous transforms, ROS 2 tf2 | 6 + recap | `phase1_frames.py` |
| 2 | **Sensors**: the pinhole camera and calibration, lidar, radar and Doppler, IMU bias and drift, GNSS/RTK, odometry, ultrasonics, time sync and the trade-off table | 7 + recap | `phase2_sensors.py` |
| 3 | **State estimation**: belief, the Bayes filter, the Kalman filter, EKF and UKF, particle filters, GPS + IMU and visual-inertial fusion, outlier gating | 7 + recap | `phase3_filters.py` |
| 4 | **Geometric vision**: features and ORB, RANSAC, epipolar geometry, stereo depth, optical flow, visual odometry, bundle adjustment and SfM | 7 + recap | `phase4_vision.py` |
| 5 | **Mapping & localization**: occupancy grids, SLAM, pose graphs and loop closure, ICP and lidar/visual SLAM, HD maps vs mapless, localizing against a map | 6 + recap | `phase5_mapping.py` |
| 6 | **Learned 3D perception**: lidar detection (PointNet → PointPillars), camera-to-BEV, occupancy networks, lanes and topology, multi-object tracking, fusion and monocular depth, the data engine | 7 + recap | `phase6_perception.py` |
| 7 | **Prediction & planning**: multimodal motion prediction, Dijkstra and A*, Hybrid A*, RRT and RRT*, lattice and Frenet planners, behavior and cost functions, trajectory optimization and interaction | 7 + recap | `phase7_planning.py` |
| 8 | **Control & dynamics**: PID, the bicycle model, pure pursuit and Stanley, LQR, MPC, quadrotor dynamics, cascaded flight control in PX4/ArduPilot, drone autonomy | 8 + recap | `phase8_control.py` |
| 9 | **Learning-based autonomy, safety & scale**: imitation learning and DAgger, end-to-end driving, world models and generative simulation, sim-to-real, the fleet data engine, safety validation and standards, remote assistance; graduation | 7 + graduation | `phase9_learning.py` |

68 lessons and 10 recaps, about 32 hours of reading and playing (the per-lesson estimates are in `assets/course.js`).

## Labs

One NumPy lab per phase in `labs/`, with `# %%` cells you can run one by one in VS Code, small TODOs, and ✅ checks after each. Solutions are in `labs/solutions/`. Everything runs on a laptop CPU in seconds.

```bash
cd ~/autonomous-systems/labs
pip install -r requirements.txt          # numpy (matplotlib optional)
python3 phase3_filters.py                 # stops at the first TODO
MPLBACKEND=Agg python3 solutions/phase3_filters.py   # all ✅
```

## Structure

```
index.html            home + roadmap (rendered from COURSE in assets/course.js)
review.html           spaced-repetition review of every lesson quiz
glossary.html         searchable glossary (generated by tools/build-glossary.py from tools/glossary/*.json)
assets/style.css      design system (callout boxes, color language, playgrounds)
assets/course.js      course manifest, nav/sidebar, progress, quizzes, MX math helpers
assets/sim.js         2D world for playgrounds: cars, drones, robots, obstacles, lidar raycasts, motion models, step loop
assets/space.js       3D rotations, quaternions, homogeneous transforms and an orbit view (View3D)
assets/plane.js       2D math plane with draggable vectors
assets/flow.js        animated pipeline diagrams (the autonomy stack)
assets/plot.js        tiny canvas charts (line, bars)
assets/review-bank.js generated by tools/build-review-bank.py (rerun after editing quizzes)
phase0/ … phase9/     lessons + recap.html per phase (phase3/3-kalman-filter.html is the reference lesson)
labs/                 one Python lab per phase + solutions/
tools/                headless page test harness, review-bank and glossary builders, facts.md (verified, dated facts)
AGENTS.md             how lessons are written (anatomy, rules, verification)
```
