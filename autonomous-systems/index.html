🔬 How to study this course
  • Guess before you look. Every lesson asks you to predict something first. Being wrong on purpose is how intuition gets built.
  • Break the playgrounds. Every one has a way to make the filter diverge, the robot get lost or the drone crash. Find it, then find the fix, then beat the 🏆 target.
  • Run the labs. Each phase has a NumPy lab (labs/) where you implement the core algorithm yourself in a few lines per TODO.
  • Follow the three companies. Read the 🚗 boxes across phases: you'll see Tesla's, Waymo's and drone makers' choices fit together into three different philosophies.
  • Teach it back. At the end of each phase, explain the big idea out loud in 60 seconds, like you would in an interview. Use ← / → to move between lessons.
  • Math when you want it. Formulas link to the Math for AI course; neural-network internals live in the Deep Learning course; imitation and model-based learning in RL from Zero.
